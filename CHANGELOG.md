# Изменения

## v5 — видимый Chrome и локальный рабочий кабинет

- HTTP → Chrome при ошибке, ручная проверка в видимом окне, ожидание стабильной карточки и закрытие окна после чтения. Отдельный профиль приложения; без stealth и автоматического решения CAPTCHA.
- Python-сервер на 127.0.0.1: импорт с прогрессом/отменой, кеш и сохраняемые ссылки на готовые карточки, редактирование по той же ссылке.
- Лаунчер start-redcn.command с установкой необязательной зависимости в .venv. Исправлен ввод ссылок из Markdown и строк с ошибкой.
- Вариативные заголовки, подача текста и контекстные теги; заметки CN | RU | варианты для проверки слов.
- 34 JavaScript + 22 Python тест, включая резервный загрузчик, жизненный цикл Chrome, отмену, локальные API, сохранение и защиту запросов.

## v4 — китайские источники, база знаний и GitHub Pages

- Проверены поисковые подсказки Rednote и китайские источники; отчёт и источники сохранены. Подтверждённые временные ряды по тегам не получены и не подменены оценками.
- Добавлены память входящего контента, заметки/термины/недочёты, проверка и ручное применение знаний, экспорт/импорт.
- Добавлена аналитика CSV/JSON за 1/7/30 дней с источниками, учётными границами и отсутствующими значениями.
- Опубликован автономный сайт https://leunch4off.github.io/redcn/ из main/docs; репозиторий открыт по указанию владельца. Исправлена сборка inline JavaScript.
- 33 JavaScript + 10 Python проверок; автономная страница и память знаний проверены в браузере.


## v3 — редакционный кабинет и CLI

- Создан главный issue Roadmap с 200 критериями приёмки; plan.json и ROADMAP.md сохраняют постоянные ID, приоритеты, зависимости и доказательства.
- Вложение пользователя сохранено без изменений и связано с назначением функций.
- Добавлены Python CLI и единый JS-генератор, SQLite-кеш, batch-отбор собственников/комиссии ≤50%, учёт seen и скачивание доступных OG/JSON-LD фото.
- Добавлены контекстные теги по метро, вузу, кампусу, планировке и подтверждённым признакам; каталог пользовательских тегов имеет русские значения и пояснение выбора.
- Реализованы динамические формулы заголовков и ротация без перезаписи описания.
- Китайские фразы кликабельны: RU-значение, варианты, поиск, выбранное/все совпадения, пользовательский словарь и отмена.
- Добавлены JSON-импорт результата CLI, базовая галерея, seller/commission-фильтр библиотеки и экран Roadmap.
- Проверки: 21 JavaScript + 10 Python; desktop-приёмка ключевых сценариев. Подробности и ограничения: docs/VERIFICATION.md.
- В реестре отражены 119 реализованных пунктов из 200, включая прежнюю функциональность. 81 остаются в плане; главный issue остаётся открытым.
