# redcn · МОСТ — CIAN → 中文 → Rednote

Закрытый рабочий инструмент для подготовки китайских объявлений о московской недвижимости. Не требует ключа ИИ: факты, редактируемые правила и воспроизводимые шаблоны.

**Рабочий сайт:** https://petrov-rednote-studio.vichnewka.chatgpt.site (доступ владельцу через ChatGPT).

## Возможности

- Три варианта китайского заголовка отдельно от описания. Ручное редактирование, счётчики, копирование заголовка / описания / всего поста.
- Три стиля: короткий, подробный по блокам и рассказ. Планировки Studio, классическая, евро-2 и евро-3.
- Площадь, кухня, жилая площадь, спальня, этажность, аренда, залог, формат цены W, расчёт бюджета на человека.
- Несколько станций и вузов с диапазонами времени, способом поездки и линией. Динамические теги без автоматического добавления неуказанных вузов.
- 20 отметок мебели и техники по зонам; детерминированный разбор текста с осторожной обработкой отрицаний и обещанной установки.
- Условия коммунальных платежей, ремонтные каникулы, дети, питомцы, короткая аренда.
- Бесплатная регистрационная помощь, сроки и количество людей, трансфер, багаж, редактируемый блок преимуществ и контакты.
- Словарь русских триггеров и китайских формулировок. Для неизвестных русских фраз показывается сообщение о необходимости перевода.
- Импорт открытой HTML-страницы ЦИАН / Авито, браузерный кеш на 24 часа (до 20 страниц), ручная вставка при блокировке источником.
- Сохранение карточек, черновика и отредактированного поста, поиск, JSON-экспорт / импорт, совместимость с резервной копией v1.

## Запуск без установки зависимостей

Нужен Node.js 22+.

```bash
git clone https://github.com/leunch4off/redcn.git
cd redcn
npm run dev
```

Открыть http://localhost:3000. На локальном превью импорт ссылок выключен; на сайте он обслуживается Worker.

```bash
npm test
npm run build
npm run validate
```

## Исходники

| Файл | Назначение |
| --- | --- |
| `web/engine.mjs` | Правила, словарь, извлечение фактов и генератор |
| `web/app.js` | Состояние редактора, библиотека, резервные копии |
| `web/index.html`, `web/styles.css` | Интерфейс |
| `worker/server.js` | Ограниченный HTTPS-импорт ЦИАН и Авито |
| `scripts/build.mjs` | Сборка самодостаточного Worker |
| `tests/engine.test.mjs` | Проверки генерации и разбора |
| `.openai/hosting.json` | Существующий закрытый сайт Sites |

`worker/index.js` генерируется сборкой. Меняйте исходники в `web/` и `worker/server.js`.

## Формат маршрутов

Одна строка — один маршрут:

```text
Прокшино | 12 | walk | 1
Филатов Луг | 19 | walk | 1
МГУ | 35–50 | public
```

`walk` — пешком, `bus` — автобус, `metro` — метро, `public` — общественный транспорт. Маршруты до вузов вводятся в отдельное поле. Все значения в примере демонстрационные.

## Ограничения и данные

- Библиотека, словарь, кеш и черновики находятся в localStorage текущего браузера. Между устройствами не синхронизируются. Для переноса используйте резервную копию.
- Защита источника, перенаправления и CAPTCHA могут не позволить импортировать ссылку. В таком случае вставьте текст вручную. Скрипт не обходит защиту.
- Это генератор по правилам, а не универсальный переводчик. Неизвестные слова остаются на исходном языке и требуют добавления перевода.
- Время в пути не рассчитывается по карте; имена станций и вузов в словаре являются редактируемыми рабочими переводами, не заявлением об официальном наименовании.
- Мебель и факты не определяются по фотографиям. Авторазбор является подсказкой и требует проверки.
- Регистрационная услуга обозначается как 临时居住登记 (временная регистрация), без обещания выдачи визы. Срок, количество людей и факт бесплатной услуги задаются оператором.
- Изменения в GitHub не развёртываются автоматически в Sites. Публикация производится отдельно после проверки.

Доступ к сайту обеспечивает Sites; локальный сервер не является защищённым хостингом для публикации в интернете.
