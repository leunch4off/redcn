# redcn · МОСТ — CIAN → 中文 → Rednote

Инструмент для подготовки китайских объявлений о московской недвижимости: импорт, проверка фактов, редактируемые шаблоны, фотографии, оформление и экспорт. В установленной версии Mac основные кнопки пишут индивидуальный текст локальной моделью по фактам квартиры и принятым фото-находкам. Генератор по правилам остаётся доступен в автономном режиме; его результат не выдаётся за ответ модели.

Текущий выпуск исходников: [v31 — совместимость, устойчивый каталог и индивидуальный текст](docs/RELEASE-v31.md), ветка [`feature/rcn-v8-knowledge-photos`](https://github.com/leunch4off/redcn/tree/feature/rcn-v8-knowledge-photos). Состояние нативных проверок, CI и установки фиксируется отдельно в [VERIFICATION.md](docs/VERIFICATION.md) и [PR #6](https://github.com/leunch4off/redcn/pull/6).

| Режим | Возможности |
| --- | --- |
| Локальный сервер на Mac | Импорт через Chrome, карточки, фотографии, досье, локальный ИИ и материалы |
| Телефон, подключённый к Mac | Работа с той же библиотекой в пределах выданной роли; Mac должен оставаться включённым |
| [GitHub Pages](https://leunch4off.github.io/redcn/) | Статический редактор с отдельным браузерным хранилищем; версия из `main/docs` может отставать от рабочей ветки |
| `npm run dev` | Превью интерфейса на порту 3000; серверные функции Mac здесь не запускаются |

Push в рабочую ветку сохраняет исходники и запускает CI. Обновление `main`, GitHub Pages и публикация приватного Sites выполняются отдельно.

## Что проверено в v29

На Mac выполнены два текстовых обучения по 240 шагов — **480 шагов суммарно**. Оба кандидата не прошли проверку прямых ответов и не заменили выбранный адаптер `balanced`. Снижение учебного loss отдельно от качества объявлений: [отчёт обучения](docs/TEXT-QUALITY-v29.md), [итоговый контроль кандидата B](docs/benchmarks/text-quality-v29-postfix-control-public.json).

Режим рекламной структуры использует **48 конечных вариантов** для неизменной карточки: модель выбирает оформление, а проверенный генератор переносит полные блоки фактов. Нативное сравнение завершило 90/90 запросов; серия для 10 карточек дала по 20 различных подач, всего 200/200 без повторов. Между двумя проверками есть 30 общих генераций, поэтому выполнено **260 уникальных вызовов**. Все они завершились EOS. Это результат ограниченного режима; свободное написание фактов моделью и китайская редактура остаются отдельными проверками. [Публичный отчёт структуры](docs/benchmarks/text-structure-v29-native-public.json).

Сквозной сценарий v29 на Mac прошёл за **134,288 с**: реальные MLX и ONNX, ручная правка, согласованные HTML/PNG/PDF/ZIP, отклонение устаревшего комплекта, проверка версий и диагностического архива. Текст кандидата B потребовал запасного генератора; фотоисполнение проверено на синтетическом пустом кадре без оценки точности распознавания. Телефонная оболочка проверена в Chrome 393 × 852; физический iPhone ещё требует приёмки. [Полный результат и границы](docs/PROJECT-RELIABILITY-v29.md).

Добавлены происхождение и отзыв учебных примеров, история кандидатов, приватная фоторазметка с рамками и решениями оператора, перенос памяти обучения и восстановление заданий. Ресурсный сценарий на Mac с 8 GiB прошёл 13 проверок за 35,765 с; остановка при недостатке памяти проверена управляемым повышением порога на реальных показаниях, без доведения системы до OOM. Новых человеческих фото-меток и допущенных фото-категорий этот выпуск не создаёт автоматически.

Нативный браузерный срез: первоначально 20/23, затем успешный повтор трёх исправленных тестовых фикстур; итоговый Node — 603 pass / 0 fail / 1 optional skip. CI точного коммита и сверка установки публикуются в PR и roadmap issue. Двухчасовой нагрузочный результат относится к замороженной базе v28 с четырьмя файлами стенда; финальный core v29 проверен отдельным сквозным сценарием. Физический сон/пробуждение Mac не измерен.

## Запуск на Mac

Для первого получения текущей рабочей ветки:

```bash
git clone --branch feature/rcn-v8-knowledge-photos --single-branch https://github.com/leunch4off/redcn.git
cd redcn
bash start-redcn.command
```

Нужны Python 3.10+, Google Chrome и Node.js 22+. Лаунчер использует `.venv` проекта и при необходимости устанавливает зависимости импорта и обработки фотографий. [Полная инструкция CLI](docs/CLI.md).

Уже работающий сервер открывается с входом владельца командой из каталога проекта:

```bash
.venv/bin/python scripts/open-local-workspace.py
```

Секрет не требуется вводить или копировать. После этого обычная перезагрузка сохраняет вход. Подключение телефона описано в [инструкции iPhone](docs/IPHONE.md).

Для превью интерфейса достаточно Node.js 22+: `npm run dev`, затем `http://127.0.0.1:3000/`. Проверки и сборка:

```bash
npm run build
PATH="$PWD/.venv/bin:$PATH" npm test
npm run validate
npm run validate:pages
```

Полный набор тестов использует также Python проекта; добавление `.venv/bin` действует только для этой команды и не меняет системный Python. Результаты приёмки и ограничения текущего выпуска — в [журнале проверок](docs/VERIFICATION.md).

## Формат маршрутов

Одна строка — один маршрут:

```text
Прокшино | 12 | walk | 1
Филатов Луг | 19 | walk | 1
МГУ | 35–50 | public
```

`walk` — пешком, `bus` — автобус, `metro` — метро, `public` — общественный транспорт. Маршруты до вузов вводятся в отдельное поле. Все значения в примере демонстрационные.

## Ограничения и данные

- Локальный сервер хранит карточки и рабочие данные на Mac; браузер дополнительно сохраняет черновики и настройки интерфейса. Авторизованный телефон обращается к тому же серверу. GitHub Pages имеет отдельное браузерное хранилище и не подключается к базе Mac автоматически.
- Защита источника, перенаправления и CAPTCHA могут не позволить импортировать ссылку. В таком случае вставьте текст вручную. Скрипт не обходит защиту.
- Генератор по правилам дополняется локальным переводом и текстовой моделью. Их результат остаётся черновиком для проверки; неизвестные и неподтверждённые формулировки нельзя автоматически считать правильными.
- По явному запросу подключаемый провайдер Valhalla/FOSSGIS рассчитывает пеший или автомобильный маршрут по двум выбранным координатам. Результат содержит дату и срок актуальности. Автобусы, пересадки и расписания этим адаптером не рассчитываются. Рабочие переводы метро/вузов не считаются официальными без отдельного основания.
- Фотоанализ предлагает предметы для проверки; отсутствие находки не означает отсутствие предмета. Включение модели и автоприменение — разные настройки. Оригиналы сохраняются; подрезки, варианты и ручные связи экземпляров учитываются отдельно.
- Проверка настроек и ответа сервера без запуска моделей: `.venv/bin/python scripts/ai-status.py --server`. Настройка «включено», наличие файлов и живой worker — отдельные состояния.
- Регистрационная услуга обозначается как 临时居住登记 (временная регистрация), без обещания выдачи визы. Срок, количество людей и факт бесплатной услуги задаются оператором.
- Изменения в GitHub не развёртываются автоматически в Sites. Публикация производится отдельно после проверки.
- Полная переносимая копия требует сохранённых оригиналов и восстанавливается в новую папку. Облачная отправка и уведомления включаются владельцем отдельно; установка обновления их не активирует.

Доступ к приватному Site обеспечивает Sites. Desktop-сервер слушает loopback; телефон использует отдельный авторизованный интерфейс и отдельно настроенный доступ к Mac.

## Ход работы локального ИИ

При импорте объявления на Mac и телефоне показываются текущая задача ИИ, модель, номер обрабатываемого фото и затраченное время. Во время генерации текста отображаются измеренные счётчики модели; загрузка модели входит в общее время запроса.

- **Текстовая MLX-модель:** число созданных токенов, токены/с и время генерации из её потоковых измерений. Скорость появляется после первых токенов.
- **Фото-модель Ollama:** токены/с показываются, когда модель вернула собственные счётчики ответа. Время обработки фотографии показывается отдельно.
- **Детектор `redcn-furniture-v1`:** время распознавания и фото/с. Этот детектор не генерирует текстовые токены, поэтому токены/с к нему не применяются.
- **Результат из кеша:** помечается отдельно; скорость старого запуска не выдаётся за новое измерение. При остановке запроса таймер останавливается.

Измеренная скорость не является оценкой точности. Автодобавленные предположения детектора сохраняются в журнал проверки и требуют подтверждения перед использованием в описании. Панель прогресса содержит только этапы и счётчики, без текста запросов, исходных фотографий и локальных путей.

### v10: код входа, дизайн публикации и архив квартиры

На Mac → «Телефон» постоянно виден обновляемый код из 8 цифр: его можно ввести в установленном приложении iPhone, если Safari и экран «Домой» запросили отдельное подключение. QR остаётся доступным.

Раздел «Дизайн» содержит три стиля, настройку intro/коллажа и outro с картой, перестановку блоков, общий шаблон JSON и предпросмотр HTML/PDF. Chrome на Mac автоматически создаёт PDF из того же HTML; готовые PNG, HTML и PDF доступны в карточке с телефона. В «Архиве квартиры» сохраняются статус сдачи, заметки, договоры, планировки и исходные LiDAR/3D-файлы до 40 МиБ. Личные вложения отделены от рекламного экспорта. [Порядок работы и ограничения](docs/DESIGN-AND-ARCHIVE.md).

### Работа с улицы и скорость v11

На Mac: **Телефон → Работа с улицы → Включить доступ из интернета**. Откройте выданную HTTPS-ссылку на iPhone и войдите по коду. Временный адрес меняется после перезапуска туннеля; старую локальную иконку нужно заменить установкой с внешней ссылки. [Настройка, проверенные времена и границы](docs/INTERNET-AND-SPEED.md).

### Подключение и диагностика v12

Автозапуск после входа в macOS: `.venv/bin/python scripts/macos-service.py install`. На телефоне видны реальные этапы загрузки и время; на Mac кнопка «Проверить соединение» отдельно проверяет телефонный сервер, DNS и HTTPS. В «Другой HTTPS-адрес» можно подключить Tuna, ngrok или свой VPS вместо Cloudflare. [Пошаговая инструкция и сравнение для РФ](docs/CONNECTION-RU.md).

### Импорт и автоматические фотографии v13

Фоновый сервер находит установленный Node.js до открытия Chrome. На телефоне видны этапы чтения страницы, прокрутки, генерации и фото, прошедшее время и среднее по успешным операциям. Задание восстанавливается при возврате в приложение. Фото автоматически проверяются и безопасно кадрируются на Mac; по умолчанию галерея и ZIP используют полный набор готовых копий с оригиналами там, где обрезка не подтверждена. [Подробности и ограничения](docs/IMPORT-AND-AUTO-PHOTOS.md).
