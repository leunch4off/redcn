## Фото-ИИ: что действительно выключено и что требуется для запуска

`cli/photo_ai_settings.py` задаёт `enabled=False`; выключенный или некорректный config возвращает `photoInventory.state=disabled`, без 30 попыток native-классификации. Важное исключение: если сохранённого config нет, валидная переменная `REDCN_VISION_MODEL` включает прежний режим совместимости. Явный сохранённый `enabled=False` имеет приоритет. В этой части фактическая среда запущенного Mac не читалась, поэтому проверка исходников не подменяет проверку его рабочего config.

`cli/photo_ai_runtime.py` прочитан целиком. `ensure_started` допускает старт только на Darwin, при `enabled is True`, точном приватном endpoint `127.0.0.1:11435`, наличии ранее установленного приложения/manifest и существующих ключей. Он вызывает только stage start, учитывает отмену/общий срок, не скачивает модель и не создаёт ключи. Фоновый поток один, ошибка опциональна. Настройки по умолчанию указывают порт 11434, а собственный helper обслуживает 11435: для него нужен явно согласованный config. Автоматическое исправление порта или включение модели не выполнялось.

Дополнение из отдельной свежей read-only проверки главного исполнителя на Mac: рабочий HEAD там `ad533485435d517484c7f41e3b35b41915f7ec0b`, дерево чистое. Сохранённый config содержит `enabled=False`, модель `qwen3-vl:2b-instruct-q4_K_M`, endpoint `http://127.0.0.1:11434`, `autoApply=True`, `maxSeconds=600`. Запросы GET `/api/version`, `/api/tags`, `/api/ps` на этом настроенном endpoint каждый завершились `URLError`. Это подтверждает выключенную рабочую конфигурацию и недоступность **настроенного** endpoint для этих запросов. Оно не устанавливает причину сетевой ошибки, отсутствие runtime на другом порту или качество распознавания. Проверка приватного порта 11435 учитывается отдельно; никаких настроек этим наблюдением не изменяли.

`listing_photo_inventory.py` ограничивает проход 30 выбранными оригиналами, общим бюджетом и максимум 120 с на кадр; дубликат по SHA получает отдельную строку без повторного анализа. Отсутствующий оригинал, timeout, плохой ответ и усечение делают охват частичным. Допустимый положительный ответ сохраняет связь с originalId/photoId; autoApply и ручная проверка имеют разные роли. `autoEligible` — флаг политики, самооценка confidence не является измеренной точностью.

Реальный старый пилот из `VERIFICATION.md`: два из трёх ответов компактного протокола усечены, в третьем шторка ванны ошибочно названа оконной шторой. Поэтому полнота распознавания кроватей/диванов/всей техники не доказана. Не готовы независимая разметка всех нужных классов, матрица пропусков/ложных добавлений и замеры памяти M2/8 GB. Главный исполнитель проверит нативный runtime отдельно; это не разрешает автоматическое включение в рабочие карточки.
