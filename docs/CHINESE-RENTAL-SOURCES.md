Все переводы имеют `origin: editorial`: это составленные для проекта короткие словарные единицы. `sourceIds` и `evidenceRelation` обозначают контекст терминологии, а не утверждают, что вся русско-китайская пара дословно взята с указанной страницы. У источников сохранены URL, дата проверки, наблюдённые термины и SHA-256 полученного HTML. Хеш фиксирует конкретный ответ при проверке; страница может позднее измениться.

Категория `conversation` содержит вопросы, просьбы и служебные фразы. Её нельзя использовать как положительные сведения об объекте. Например, «есть ли в квартире мебель» переводится вопросом; это не подтверждение наличия мебели.

## Естественная подача объявления

По московским обсуждениям и публичным заметкам полезна последовательность: **место → тип аренды → планировка → подтверждённое оснащение → цена и платежи → условия → просмотр**. В коротком варианте достаточно трёх–пяти блоков. Порядок и внешний вид блоков можно менять, сохраняя факты. Количество возможных сочетаний блоков следует показывать отдельно от числа словарных записей и числа реально написанных объявлений.

Собственные редакционные конструкции, которые можно собирать из полей карточки:

| Назначение | Конструкция | Условие использования |
|---|---|---|
| Заголовок с местом | `{地铁站}附近 · {户型}` | Станция и тип жилья подтверждены |
| Заголовок с ценой | `{区域}租房｜{月租金}卢布/月` | Район и месячная цена известны |
| Заголовок с оснащением | `{户型}出租，配有{已确认家具}` | Перечислять только подтверждённые предметы |
| Транспорт | `步行至{地铁站}约{分钟}分钟` | Число минут взято из источника или проверенного маршрута |
| Оснащение | `配有{家具列表}；家电包括{电器列表}。` | Непустые списки; не писать «всё есть» по двум предметам |
| Планировка | `{房间数}间居室，{厨房类型}。` | Не добавлять отдельную гостиную без данных |
| Оплата | `月租{金额}卢布，{费用说明}。` | Сохранять точные суммы и перечень платежей |
| Условия | `{入住日期}起可入住，{已确认条件}。` | Дата и разрешения известны |
| Завершение | `可预约看房，具体入住安排请确认。` | Возможность просмотра должна быть подтверждена |

Это шаблоны представления данных, а не готовые факты. Не заполнять отсутствующие поля красивыми догадками. Общие рекламные выражения вроде «идеально», «лучшее предложение», «нужно брать немедленно» не требуются для естественного китайского текста.

## Регистрация и виза

Официальное китайское напоминание студентам использует **居留登记** для российского регистрационного учёта и отдельно говорит о визе и её продлении. Для описания временной регистрации в карточке понятны **临时住宿登记** и **住宿登记**; для точного российского контекста в словарь добавлено **俄罗斯居留登记**.

**落地签 / 落地签证** обычно означает визу по прибытии. В русскоязычной китайской среде встречается разговорное употребление первого слова для регистрационного документа, но нельзя из-за этого обещать оформление визы. Если интерфейс сохраняет выбранную агентством русскую метку «виза прибытия (временная регистрация)», её пояснение должно явно сохранять смысл временной регистрации. Наличие метки в словаре само по себе не подтверждает, что собственник предоставляет услугу. Правовые сроки и юридические инструкции из источника в генератор не перенесены.

- `xiaohongshu.com`: закрытый или авторизованный корпус не исследован. Утверждения «изучен весь 小红书» нет.
- `msu.ru/ch/` и `mgimo.ru/chinese/`: успешный HTTP-ответ вернул оболочку без пригодного китайского текста; страницы не засчитаны как прочитанные источники.
- [Заметка uhomes 400088](https://www.uhomes.com/note/400088.html): обнаружено несовпадение географии заголовка и тегов. Такие теги нельзя автоматически переносить в московскую карточку.

Поисковый инструмент в этой сессии не вернул результатов. Проверенные страницы получены прямыми HTTPS-запросами, а обсуждения найдены через открытый поиск и ссылки самого Douban. Это ограниченный проверяемый набор источников; для расширения нужны новые доступные страницы и повторная редакционная проверка.
