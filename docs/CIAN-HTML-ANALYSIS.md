# Разбор приложенного HTML ЦИАН и заполнение редактора

Источник — `untitled text.html`, переданный владельцем 30 октября 2026 года. Анализ относится к сохранённому файлу, а не к актуальности предложения на площадке. Полный HTML со служебными данными не публикуется в репозитории. Fixture для тестов содержит выбранные данные объявления и искусственные тестовые маркеры.

Основной разбор выделил 45 уникальных семантических блоков и 5 копий JSON состояния. Повторные блоки не увеличивают количество мебели или фотографий.

## Откуда берутся данные

| Блок / атрибут | Данные | Правило |
| --- | --- | --- |
| `#description`, `[data-name="Description"]` | Описание, мебель, отрицания, ограничения | Сохраняются пунктуация и исходные фразы |
| `OfferTitleNew`, `OfferTitle`, `h1` | Комнаты, площадь | Рекомендации не становятся фактами основной квартиры |
| `ObjectFactoidsItem` | Общая/жилая/кухня, этаж | Значение связывается с подписью |
| `OfferSummaryInfoItem` | Санузел, окна, ремонт, год, конструкция, отопление | Дополняет JSON сведениями о доме |
| `FeaturesItem`, `FeaturesLayout` | Оснащение | Общая отметка мебели не означает наличие каждого прибора |
| `PriceInfo`, `OfferFactItem` | Аренда, залог, комиссия, ЖКХ, предоплата, срок | Ноль сохраняется как ноль; неизвестное не превращается в ноль |
| `AddressItem`, `AddressContainer` | Адрес и район | Раздельные редактируемые поля |
| `UndergroundItem` | Станции, минуты | Одинаковое имя с разными путями не сливается |
| `_cianConfig['frontend-offer-card']` → `defaultState.offerData.offer` | Типизированные факты, признаки, маршруты | Из `.concat([...])` читается только валидный JSON, без выполнения JavaScript |
| JSON-LD `Product` / `Offer` | URL, описание, изображения | Дополнительный источник: в нём отсутствует часть полей |
| JSON `photos[].fullUrl` | 6 оригинальных фотографий | Убираются повторы; мебель по фото не угадывается |
| `HomeownerInfo`, `isByHomeowner` | Тип автора | Паспортная отметка не означает проверку документов нашим агентом |
| Навигация, футер, реклама, рекомендации, аналитика и кнопки | Интерфейс площадки | Не становятся характеристиками квартиры или статистикой Rednote |

Динамические CSS-классы `xa15a2ab7--…` не участвуют в правилах. Скрипты, события, рекламные пиксели и программы защиты из HTML не запускаются. Из конфигурации не переносятся телефоны, ID пользователей, ключи, отслеживание и произвольные настройки.

Статусы: **есть**, **нет по источнику**, **планируется**, **противоречие**, **не указано**. Обещание будущей установки не делает предмет установленным. При конфликте текста и JSON предмет не отмечается автоматически. Смешанная кириллица/латиница в `КОMИCCИИ`, `ЖИBОТНЫХ`, `нe` нормализуется для поиска; доказательство показывается в исходном написании.

## Ограничения и противоречия

- **Регистрацию не сделают:** обещание бесплатной регистрации отключается для этого объекта, причина видна в форме и тексте.
- **1 человек:** не создаётся бюджет совместной аренды на 2–4 жильцов, не обещается проживание пары или семьи.
- **Без животных, некурящим, без гостей/компаний; запрещены субаренда и посуточная пересдача:** условия сохраняются и переводятся.
- **Договор 11 месяцев против срока от года:** хранятся оба поля с предупреждением; одно из значений молча не выбирается.
- **Залог 140 000 ₽**, а не автоматически одна аренда. Комиссия — **0%**, предоплата — **1 месяц**.
- Вуз, кампус, время до университета, китайские магазины/рестораны и неподтверждённые удобства остаются незаполненными.

## Варианты и история

Меняются вступление, заголовки блоков, перечисления, призыв к обращению и контекстные теги. Цена, залог, метраж, оснащение, маршруты и ограничения сохраняются. Проверены 100 разных воспроизводимых текстов для одной карточки. Браузер помнит 200 последних отпечатков текста объекта и пропускает повторяющуюся подачу. Это конечный набор редакционных вариантов, без обещания бесконечной уникальности или охватов. CLI `--variant` воспроизводит вариант.

История фиксирует генерации, импорт, сохранения, успешные копирования и восстановления. На момент действия замораживаются точные поля, заголовок, описание, теги и доказательства, включая ручные правки. При отказе буфера успешное копирование не записывается. PNG создаётся после сохранения или успешного копирования и показывает готовую текстовую публикацию. HTML-снимок содержит все поля и доказательства. Подробности: [HISTORY.md](HISTORY.md).
