# Источники для лёгкого мониторинга ЦИАН

Проверка первичных страниц: **31 октября 2026**. Это исследование доступных интерфейсов и исходников, а не обещание, что любой из чужих парсеров сейчас успешно запустится с конкретного IP. Код сторонних проектов в redcn не переносился.

## Официальный API и поисковая выдача

[Страница Циан API](https://promo.cian.site/api) описывает подключение CRM к личному кабинету профессионала: показатели своих размещений, сообщения, сотрудники и финансы. Ключ получают в настройках кабинета. [Официальная документация](https://public-api.cian.ru/docs/latest) открывается как приложение без читаемого статического текста; её список методов здесь не объявляется полностью проверенным.

В опубликованном [Swagger-клиенте anna-romancova/cian-API-client](https://github.com/anna-romancova/cian-API-client) есть `GET /v1/get-my-offers`, отчёты, уведомления и статистика. Этот список подтверждает работу с аккаунтом, но не подтверждает безусловный доступ к произвольным объявлениям всего рынка. Сгенерированную строку клиента о том, что авторизация не нужна, нельзя использовать вместо официальных условий и ключа. Ключи, cookies и запросы в поддержку автоматически не создаются и не отправляются.

## Минимальная форма запроса, подтверждённая исходником

В `petuhovskiy/cian-search/query.json` пагинация задаётся объектом `page: {type: "term", value: <номер>}` внутри `jsonQuery`; `region` — объект `type: "terms"` с массивом значений. `_type` — строка, а не объект. Для долгосрочной аренды в примере используется `for_day: {type: "term", value: "!1"}`. В [config.example.yaml проекта Miraines](https://github.com/Miraines/real-estate-parser/blob/main/config.example.yaml) опубликована полная форма сортировки: `sort: {type: "term", value: "creation_date_desc"}` внутри `jsonQuery`. Это подтверждает форму примера, но не гарантирует сегодняшнюю доступность endpoint с нашего адреса. В нашем адаптере номер страницы ограничивается сверху; шаблон `$page` не исполняется и произвольные внешние адреса не принимаются.

## Дата размещения и новизна

В свежем описании desktop-схемы указан `creationDate`, но формат значения по этому источнику полностью не установлен. Поэтому нужны строгий разбор поддерживаемых ISO-дат/числовых временных меток, сохранение исходного значения и явное отсутствие даты, если её нет. `firstSeenAt` означает только первое наблюдение нашим монитором. Оно не подменяет дату публикации. Обновление цены или возвращение старого ID не является доказательством новой публикации.

Первый успешный снимок формирует базу сравнения. Последующие новые ID попадают в отдельную ленту. Из неё оператор сам запускает существующий полный импорт; перечитывание всех описаний, фото и мебели каждый час не требуется.

## Режим redcn

Один проход ограничен двумя страницами выбранного поиска и конечным временем ожидания. Это ограниченная выборка верхней части выдачи, **не гарантия полноты всех московских новинок за час**. Для насыщенной выдачи полезны конкретные фильтры поиска. Фоновая проверка работает, пока включён Mac и сервер redcn; пропущенные периоды не вызывают лавину накопленных запросов.

403, 429 и видимая проверка браузера отражаются в состоянии монитора. Автоматическое решение CAPTCHA, подмена IP, stealth-плагины и попытки обхода ограничений не добавляются. Если источник закрыт, список не выдаётся за успешно обновлённый.
