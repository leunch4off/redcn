# Python CLI

Нужны Python 3.10+, Node.js 22+ и установленный Google Chrome. Текстовый/HTTP-режим работает без pip-зависимостей; для запуска Chrome нужен Playwright.

## Самый простой запуск на Mac

Скачайте **весь проект**: GitHub → Code → Download ZIP, распакуйте. Нужен не один redcn.py: рядом должны быть cli/generate.mjs, web/ и docs/. В терминале из папки проекта:

```bash
bash start-redcn.command
```

Лаунчер создаст .venv, установит браузерную библиотеку при первом запуске и откроет локальный сайт. Вставьте ссылку и нажмите «Загрузить и создать». Можно выбрать «Сразу видимый Google Chrome», ожидание до 600 секунд и обновление без кеша. В консоли напечатается адрес вида http://127.0.0.1:8765/. Терминал должен оставаться открытым; Ctrl+C останавливает сайт. Повторный запуск открывает уже работающий redcn с тем же каталогом данных и браузером. Если порт занят другой программой, выбирается следующий свободный (в пределах 20 портов); чужие процессы остаются запущенными. Смотрите адрес, напечатанный в терминале. Явный порт: `bash start-redcn.command --port 8766`; случайный свободный: `bash start-redcn.command --port 0`.

## CLI с окном Chrome и готовой карточкой

Однократная установка зависимости (лаунчер делает это сам):

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r cli/requirements-browser.txt
```

```bash
.venv/bin/python cli/redcn.py --browser --open
.venv/bin/python cli/redcn.py 'https://www.cian.ru/rent/flat/300691182/' --browser --browser-timeout 300 --open
.venv/bin/python cli/redcn.py --serve
```

Первый запуск Google Chrome на Mac может занять до 90 секунд; это отдельное ожидание старта браузера перед загрузкой страницы. Первый вариант спросит ссылку. `--browser` сразу открывает обычное видимое окно Google Chrome. `--open` после генерации запускает локальный редактор с результатом и печатает постоянную ссылку этой карточки. Третий вариант сразу открывает сайт для импорта нескольких объявлений по очереди.

При проверке источника **самостоятельно пройдите её в открывшемся окне**. Программа ждёт появления фактов объявления и стабильного текста, считывает их, закрывает только своё окно импорта и формирует пост. Она не притворяется человеком и не решает CAPTCHA. Используется отдельный профиль redcn в каталоге кеша; личный профиль Chrome и его cookies не копируются. Вход в аккаунт для чтения публичного объявления не требуется.

Без `--browser` действует `--loader auto`: HTTP, затем один запуск Chrome при ошибке/проверке/тайм-ауте. `--loader http` отключает браузерный переход. Источник может ограничить и обычный Chrome; при истечении ожидания можно повторить запуск вручную или вставить текст. Режим не гарантирует доступ к снятому или заблокированному объявлению.

Ссылки в виде `[https://…](https://…)`, в угловых скобках и с приклеенным сообщением «Ошибка: …» очищаются перед проверкой домена. Кеш на 24 часа позволяет повторно генерировать пост без повторного открытия страницы. `--refresh` заставляет загрузить её заново.

## Текст, JSON, фотографии и пакет ссылок

Из корня репозитория:

```bash
python3 cli/redcn.py
python3 cli/redcn.py 'https://www.cian.ru/rent/flat/ID/'
python3 cli/redcn.py --input examples/listing.txt
python3 cli/redcn.py --input examples/listing.txt --data examples/fields.json --variant 1 --json --output output/post.json
python3 cli/redcn.py 'https://www.avito.ru/AD_PATH' --download-photos output/photos --json --output output/avito.json
python3 cli/redcn.py --batch examples/batch.json --download-photos output/batch-photos --output output/batch-results.json
```

Ссылки с ID и AD_PATH выше — заполнители; их нужно заменить настоящими ссылками. `--input` работает без сети. Для первого запуска начните с приложенного демонстрационного текста.

- `--data`: JSON проверенных полей карточки, перекрывает извлечённые значения.
- `--rules`: JSON-словарь RU→CN; `--prefs`: benefits, contact, brandTags.
- `--variant`: фиксированный вариант заголовков, формулировок и тегов. Без флага счётчик меняется при каждом запуске для той же ссылки/текста; цена, площадь и маршруты не изменяются. Бесконечная уникальность или охваты Rednote не гарантируются.
- `--json`: чистый JSON в stdout; `--output`: записать файл вместо stdout.
- `--cache-dir`: каталог SQLite (по умолчанию ~/.cache/redcn); `--refresh`: повторная загрузка.
- `--download-photos`: скачивать доступные OG/JSON-LD фото в папку с manifest.json. Ограничение 30 фото, 12 МБ на файл, JPEG/PNG/WebP.

## Манифест новых ссылок

```json
[
  {"url":"https://www.cian.ru/rent/flat/ID/", "seller":"owner"},
  {"url":"https://www.avito.ru/AD_PATH", "seller":"agent", "commission":50}
]
```

`owner` — собственник, `agent` — посредник. Комиссия — процент аренды, не сумма рублей. Программа принимает 0…50% включительно; неизвестный автор/процент не допускается в автоматический отбор. Эти поля проверяет оператор. Успешно обработанные URL попадают в seen, следующие запуски пропускают их. Ошибки не помечаются успешными. Одна ссылка может дополнительно иметь объект data с проверенными полями.

Это пакетная обработка подготовленного списка, а не работающий автоматический поиск по всем новым объявлениям площадок. Коннекторы выдачи и мониторинг перечислены отдельными задачами Roadmap.

## На сайте

Нажмите «Импорт результата Python / JSON», выберите файл одиночного результата с --json. Сайт восстановит поля, заголовки, описание, теги и доступные фото. Batch-результат — массив отчётов для обработки; его нельзя выдавать за одиночную карточку.

Локальный сайт сам получает результат из Python: три заголовка, отдельное описание, теги с объяснениями и доступные фотографии. Ссылка `/listing/<id>` хранит результат на вашем компьютере. После правок нажмите **«Сохранить правки по этой ссылке»**. Она открывается повторно после перезапуска сервера с тем же каталогом кеша и портом; на другом устройстве этот адрес не работает. «Новый объект» очищает привязку к прежней карточке.

Кнопка **«Новая подача всего текста»** меняет подачу по тем же полям и заменяет ручные правки описания после подтверждения. «Другие заголовки и теги» сохраняет отредактированное описание.

Поле «Словарь формулировок и заметки этой карточки» принимает по одной записи на строку:

```text
独立卧室 | Отдельная спальня | 单独卧室
月租 | Аренда в месяц | 每月租金
Проверить срок регистрации у собственника
```

Записи с `|` становятся подсказками в **«Проверке слов»**: нажмите китайскую фразу в заголовке/описании, увидите русский смысл и варианты замены. Обычные заметки сохраняются отдельно от текста публикации. Пользовательские формулировки не подтверждают наличие услуги или мебели. Полный словарь, база знаний, сохранение замен и резервная копия доступны и локально.

GitHub Pages не может запускать Chrome на вашем компьютере: для этого откройте именно локальную ссылку, напечатанную скриптом. `npm run dev` остаётся превью интерфейса; для рабочего импорта запускайте `--serve`.

## Ошибки

Если установленный Chrome не запускается, можно выбрать совместимый Chromium / Chrome for Testing. Однократно установите `.venv/bin/python -m playwright install chromium`, затем используйте `--browser --browser-channel chromium` или выберите его в локальном интерфейсе. Для запуска сайта с ним по умолчанию: `bash start-redcn.command --browser-channel chromium`. Профили Chrome и Chromium раздельные. Браузер выбирается для совместимости запуска, а проверка площадки остаётся ручной.

Если Chrome не открылся, проверьте наличие Google Chrome и запуск именно `.venv/bin/python`. Ошибка `_ssl...handshake...timed out` — сетевой тайм-аут HTTP; в auto-режиме после неё открывается Chrome. Если источник не разрешил чтение после ручной проверки, используйте --input. stdout содержит результат, stderr — прогресс и ошибки; код возврата 2 означает отказ. HTTP-запросы проверяют HTTPS, домен, публичный IP, редиректы и размер ответа. Фото с неизвестных CDN не скачиваются автоматически. Локальный сервер слушает только 127.0.0.1, проверяет Host/Origin и токен страницы; публикация в интернет этим сервером не предусмотрена.
