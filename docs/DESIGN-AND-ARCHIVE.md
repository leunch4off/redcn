# Дизайн публикации и архив квартиры · v10

Mac хранит карточки, фотографии, готовые рекламные материалы и личные документы. На компьютере и подключённом iPhone доступен один объект с постоянным ID. Подготовка PDF и загрузка карты выполняются на Mac; телефон получает готовые файлы.

## Вход с iPhone и экрана «Домой»

1. На Mac запустите `bash start-phone.command` или откройте работающий локальный редактор по адресу `http://127.0.0.1:8765/`.
2. Нажмите «Телефон». Если доступ выключен, нажмите «Подключить iPhone».
3. На этом экране всегда показаны текущие **8 цифр**, срок действия и QR-код. Код одноразовый, действует 10 минут и автоматически сменяется после использования или истечения. Перезагрузка страницы Mac показывает тот же действующий код. Кнопка «Новый код и QR» меняет его сразу.
4. На телефоне откройте адрес из списка на Mac и введите 8 цифр. Пробел между группами допустим. Можно также открыть ссылку из QR-кода.

Safari и установленное приложение с экрана «Домой» могут использовать разные сессии. Если новая иконка просит вход, **оставьте приложение открытым и введите в нём текущие 8 цифр с Mac → «Телефон»**. Переход по QR в обычный Safari не всегда подключает отдельное установленное приложение.

Действующие сессии сохраняются до 30 дней и переживают обычный перезапуск сервера. Создание нового кода не отключает уже подключённый телефон. «Отключить доступ» отзывает все сессии. Оба устройства должны иметь доступ к одной локальной сети; адрес `127.0.0.1` на телефоне ведёт на сам телефон.

Код не публикуется в открытом телефонном API. QR и 8 цифр хранятся в памяти сервера, на диске остаются хеши. При частых ошибочных попытках ввод временно ограничивается; сообщение показывает время ожидания.

## Выбрать карточку

На Mac откройте «Библиотека» → **«Карточки на Mac»** → «Открыть». Каталог содержит подготовленные на компьютере объекты, включая ссылки, отправленные с iPhone. Постоянная ссылка `/listing/<id>` открывает ту же карточку. Обновление текста, создание PDF и добавление договора относятся к этому ID.

На телефоне откройте квартиру из ленты. В карточке доступны «Дизайн», «Готовые материалы» и «Архив квартиры». Для нового объекта сначала заполните описание; сохранение материалов или архива закрепит карточку на Mac.

## Общий шаблон для следующих квартир

Откройте **«Дизайн» / «Дизайн и PDF»**, затем «Обновить из карточки». Предпросмотр использует текст и загруженные фотографии выбранного объекта. Для знакомства с интерфейсом нажмите **«Демо дизайна»**: это явно отмеченный учебный макет со схематичным изображением. Чтобы вернуться к квартире, нажмите «Обновить из карточки».

Вкладка «PDF / HTML» содержит:

- Три начальных стиля: «Редакционный · тёплый», «Минимальный · светлый», «Вечерний · тёмный».
- Цвета акцента, фона и текста, шрифт PDF, формат A4 или Letter, контакт и подпись бренда.
- Блоки «Обложка intro», «Название», «Цена и параметры», «Описание», «Фотографии», «Расположение / outro», «Контакт и подпись». Галочки включают блоки; стрелки меняют их порядок.
- «Сохранить общий шаблон»: сохраняет оформление на Mac для следующих карточек. Текущие правки также сохраняются в браузере.
- Экспорт и импорт шаблона JSON для переноса настроек. Импортируется шаблон МОСТ версии 1; затем нажмите «Сохранить общий шаблон», чтобы применить его на сервере.

Общий шаблон хранит оформление и подстановки. В него не нужно вручную переписывать данные следующей квартиры. Доступные поля: `{{title}}`, `{{price}}`, `{{metro}}`, `{{area}}`, `{{address}}`, `{{rooms}}`, `{{floor}}`.

## Intro и outro

**Intro · обложка** накладывает текст на фотографию или коллаж из двух/трёх фото. Можно выбрать первое фото, заголовок и подзаголовок, расположение текста сверху/по центру/снизу, выравнивание, размер заголовка, затемнение и показ цены, метро, площади. Для макета берутся до шести выбранных фото в установленном порядке. Внутренний предпросмотр показывает результат; **«Скачать PNG»** создаёт изображение 1080 × 1440.

**Outro · финал** содержит заголовок, подпись/адрес, расположение, контакт и бренд. Карта строится из координат выбранной карточки с реальными фрагментами OpenStreetMap и отметкой точки. Указание авторства сохраняется внутри изображения и в HTML/PDF. Проверьте координаты объекта перед отправкой клиенту: адрес не превращается в выдуманную точку и время в пути не вычисляется по картинке.

Если карта недоступна, остаются адрес, координаты и ссылка на OpenStreetMap в HTML/PDF. Если координат нет, предпросмотр сообщает, что расположение не определено. Показ расположения можно выключить. Готовый outro также сохраняется как PNG 1080 × 1440.

Оригиналы фотографий не перезаписываются. Intro и outro появляются отдельными материалами объекта.

## HTML → PDF

1. Настройте общий шаблон и проверьте предпросмотр на вкладке «PDF / HTML».
2. Нажмите **«Скачать HTML»**. Файл содержит дизайн, текст и встроенные фотографии; его можно открыть отдельно от сайта.
3. Нажмите **«Скачать PDF»**. Mac автоматически передаёт тот же HTML в Google Chrome и сохраняет PDF. Вручную импортировать HTML в отдельную программу не требуется.
4. Для следующего объекта откройте его карточку и нажмите «Обновить из карточки»: сохранённое оформление применяется к новым данным.

Предпросмотр показывает HTML-макет; окончательное разбиение по страницам выполняет Chrome с выбранным форматом бумаги. PDF создаётся для выбранной реальной карточки; учебный режим предназначен для настройки и предпросмотра.

В экспорте используются до шести подготовленных фотографий, а для коллажа — до трёх. Неизвестные сведения о квартире не заполняются предположениями. Дизайн настраивается предусмотренными блоками и полями; импорт общего шаблона выполняется через JSON.

Созданные intro/outro, HTML и PDF сохраняются на Mac и перечисляются в **«Готовые материалы»**. На телефоне откройте ту же квартиру, нажмите «Обновить материалы» и скачайте нужный файл. PNG можно сохранить в «Фото» через доступное системное меню iPhone; PDF, HTML и ZIP сохраняются в «Файлы».

Кнопка **«Показать готовый PDF»** открывает уже созданный файл с настоящими страницами. Предпросмотр HTML служит для редактирования; переносы страниц проверяются в готовом PDF. Из диалога файл можно открыть отдельно.

## Архив после сдачи квартиры

В выбранной карточке откройте **«Архив квартиры»**:

1. Выберите статус «В работе», «Сдана» или «В архиве».
2. Запишите личные заметки, например дату сдачи и особенности следующего заселения, и сохраните изменения.
3. Выберите категорию «Договор», «Планировка», «LiDAR / 3D» или «Другой файл», затем прикрепите файл.
4. В списке вложений доступны имя, категория, дата, размер, скачивание и удаление с подтверждением.

Один файл — до **40 МиБ** (41 943 040 байт). Поддерживаются PDF, JPG/JPEG, PNG, WEBP, DOCX, TXT, ZIP, USDZ, OBJ, GLB, GLTF, PLY, STL, DXF и IFC. LiDAR-сканы и модели сохраняются в исходном формате для будущего клиента. Встроенный просмотр/редактирование 3D, сканирование LiDAR телефоном и подписание договоров в эту функцию не входят.

Договоры, личные заметки и вложения **не включаются в рекламные фото, HTML и PDF-презентацию**. Они доступны внутри подключённой карточки владельцу сессии, в том числе на iPhone. Пометка «Только для вас» означает отделение личного архива от рекламного экспорта; отдельные роли клиентов пока не предусмотрены.

Архив и материалы привязаны к постоянному ID на Mac и сохраняются при обновлении текста карточки. Браузерный JSON-экспорт библиотеки не переносит бинарные вложения и серверные материалы: скачивайте нужные исходные файлы отдельно.

## Запуск и проверки

Для автоматического PDF нужны Google Chrome и браузерные зависимости локального проекта. Используйте существующий запуск:

```bash
bash start-phone.command
```

Команды функциональной и браузерной проверки:

```bash
PYTHONPATH=tests .venv/bin/python -m unittest test_card_api test_card_assets test_pairing_codes -v
PYTHONPATH=tests .venv/bin/python -m unittest test_pairing_browser test_presentation_browser -v
npm test
npm run build
npm run validate:pages
```

Браузерные сценарии используют изолированные данные и Playwright/Chrome. Проверка установки, клавиатуры и системного сохранения файлов на физическом iPhone выполняется отдельно.

Карта использует [официальную политику тайлов OSM](https://operations.osmfoundation.org/policies/tiles/); PDF создаётся через [Playwright Python Page.pdf](https://playwright.dev/python/docs/api/class-page#page-pdf).
