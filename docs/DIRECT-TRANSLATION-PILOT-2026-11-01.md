# Изолированный пилот прямого перевода китайский → русский

Дата: 2026-11-01. Это исследование одного кандидата, без замены рабочего переводчика, конфигурации, сервера или правил добавления объявлений.

## Кандидат и лицензия

Вместо отсутствующих точных идентификаторов `Helsinki-NLP/opus-mt-ru-zh` и `opus-mt-zh-ru` найден официальный **Tatoeba-Challenge `zho-rus/opus-2021-05-16`**, transformer-align с SentencePiece 32k. Он переводит китайские языковые варианты в русский; русский → китайский и создание JSON-объявлений ему не приписываются.

Первичные источники:

- [Карточка модели zho-rus](https://github.com/Helsinki-NLP/Tatoeba-Challenge/blob/master/models/zho-rus/README.md), git blob `ec1716c92ad8eee951ec2ff4562d342d02ed49ce`.
- [Лицензия именно каталога моделей](https://github.com/Helsinki-NLP/Tatoeba-Challenge/blob/master/models/LICENSE), CC-BY-4.0, git blob `2fb94156cd39cad415432aeb1ac5b38d5cb53e1e`. Корневая лицензия набора обучающих данных отличается; лицензия программного кода не использовалась как доказательство лицензии весов.
- [Официальное описание OPUS-MT](https://github.com/Helsinki-NLP/Opus-MT/blob/master/README.md), git blob `a241405f37691e3872d25e15126592d578f875d9`, отдельно подтверждает CC-BY-4.0 для моделей OPUS-MT и Tatoeba Challenge.
- [Официальный архив весов](https://object.pouta.csc.fi/Tatoeba-MT-models/zho-rus/opus-2021-05-16.zip).
- [CTranslate2: OPUS-MT](https://opennmt.net/CTranslate2/guides/opus_mt.html), [Marian](https://opennmt.net/CTranslate2/guides/marian.html), [ARM64 CPU](https://opennmt.net/CTranslate2/hardware_support.html).

Атрибуция: Helsinki-NLP / OPUS-MT / Jörg Tiedemann; Tatoeba Translation Challenge (`2020.wmt-1.139`). Изменение: конвертация официальных Marian-весов в CTranslate2 int8 для локального исследовательского запуска. Веса в репозиторий не добавлены.

Обратное направление не объявлено отсутствующим вообще: официальный [sla-zho](https://github.com/Helsinki-NLP/Tatoeba-Challenge/blob/master/models/sla-zho/README.md), blob `98a87de6ed5ae2170be7302b4012f48c878ed812`, включает русский и китайский, но архив `opusTCv20210807_transformer-big_2022-09-14.zip` имеет 884,792,675 байт. В рамках одного небольшого кандидата он не загружался.

## Проверяемые артефакты

Архив: **283,528,302 байта**, SHA-256 `22b2dc9ceadae15b6b7f1041e9618aad813467b6f2c1877c9bc3c9d6de98e1b4`. Это вычисленная контрольная сумма; независимая опубликованная SHA-256 не найдена. Проверены размер, структура ZIP, CRC; до извлечения запрещены выход за каталог, абсолютные пути, ссылки, шифрование и чрезмерный размер.

Конвертированный `model.bin`: **81,407,637 байт** (77.64 MiB), SHA-256 `c5f4f85d533a404b79892a4cd71efadbf9135fea4efd8f2ae6e66cb6d389df82`. Использован уже установленный ARM64 CTranslate2 4.8.4 из `.venv-translate`, CPU int8, два потока. Дополнительные пакеты не устанавливались.

Конвертация заняла 2.79 с, максимальный RSS отдельного процесса конвертации — 602,783,744 байта. Загрузка архива заняла 108.39 с; это разовая подготовка, а не время ответа переводчика.

Исходные и конвертированные веса оставлены в приватном кеше `tools/direct-translation/zho-rus-20210516`; активная конфигурация на них не переключена.

## Методика и ограничение первой попытки

Использованы те же **семь** независимых авторских китайских фраз из замороженного корпуса сравнения: отрицания, неизвестная комплектация, кухонная техника, кровать/диван, рубли/аренда/залог и числа. SHA-256 всего корпуса из 18 заданий: `7235774d47f19b14cae155144eb3f429e0fe99e331fbdc8aab2f30e3d48f64de`. Остальные 11 заданий отмечены неподдерживаемыми, не включены в знаменатель. Модель не обучалась на этих фразах.

Первый запуск использовал непосредственно SentencePiece и beam 4. После чтения **поставляемых с моделью** `preprocess.sh` и `decoder.yml` обнаружено, что эталонный путь предусматривает нормализацию китайской пунктуации и beam 6 с нормализацией длины. Поэтому первый результат сохранён как предварительный: [исходные измерения](benchmarks/direct-zho-rus-20261101-native.json), **2/7** частичных проверок, 0.127 с медиана, 0.216 с максимум, 204,554,240 байт RSS отдельного процесса вывода. Он не используется как итоговая оценка корректно настроенного кандидата.

Нормализация воспроизведена в Python; сторонний `preprocess.sh` не исполняется. В том числе буквально сохранено необычное upstream-преобразование `１` → кавычка; тестовые числа записаны ASCII-цифрами, поэтому это не меняет данный корпус. SentencePiece выполняет декодирование целевого текста. Один повтор той же семёрки требуется из-за конкретно выявленного расхождения с первичным пакетом, а не для перебора удачных ответов.

Каждая попытка проверяет отсутствие активных импортов и использует общий `model_resource`; занятый ресурс не обходится. Первая попытка исправленного запуска была отложена именно этим механизмом. Внешний процесс ограничен 150 с, внутренний цикл — 120 с. Приватные объявления, фото, HTML, cookies и авторизация не читались.

## Исправленный запуск и решение

[Полный результат с нормализацией и beam 6](benchmarks/direct-zho-rus-20261101-normalized-native.json) получен на Mac в отдельном ARM64-процессе, PID 5100, exit 0, 1.36 с внешнего времени. Активных импортов перед запуском: 0. Конвертация повторно не выполнялась.

| Показатель | Измерение |
|---|---:|
| Пройдено частичных проверок | **1/7** |
| Неподдерживаемые задания остальных направлений/JSON | 11 |
| Загрузка подготовленной модели | 0.045 с |
| Первая фраза после загрузки | 0.127 с |
| Медиана по семи фразам | 0.134 с |
| Максимум по семи фразам | 0.207 с |
| Максимальный RSS процесса вывода | 204,800,000 байт (195.31 MiB) |
| Цикл с загрузкой и проверками | 1.160 с |

Эти времена показывают скорость коротких фраз с прогретым файловым кешем, а не холодный старт после перезагрузки Mac. Память — RSS процесса CPU-вывода; она сопоставима по типу измерения с ранее сохранёнными RSS-процессами, а не с пиком аллокатора MLX. Модель повторно использовалась внутри процесса; медиана включает первую фразу.

Нормализация не устранила ошибки. Сохранены конкретные контрпримеры:

| Исходная задача | Фактический результат | Проблема |
|---|---|---|
| Стиральная машина есть, телевизора нет | «В квартире есть прачечные машины, но нет телевизора.» | Неточная бытовая терминология; проверка стиральной машины не пройдена |
| Холодильник не подтверждён; шкаф есть | «Устройство холодильников еще не подтверждено.» | Потерян шкаф |
| Духовка и микроволновка; компьютера нет | «На кухне есть кухня и микроволновые печи, в комнате нет компьютеров.» | Духовка заменена кухней |
| Нет двуспальной кровати, только диван | «У нас нет кровати. Только салат.» | Диван заменён салатом |
| 68,000 рублей аренда, 34,000 залог | «Ежемесячно арендовать 68 000 рублей.» | Потеряны залог и его сумма |

Также искажено условие проживания с животными. Единственная прошедшая частичные проверки фраза сохранила аренду 91,200 рублей, площадь 51.5 м² и этаж 16, но её грамматика остаётся неестественной. **1/7 — результат ограниченного автоматического экрана, не процент точности языка.**

По парной семёрке прямое направление этого кандидата не улучшило проверяемую пригодность: прежний Qwen 1.5B дал 1/7, Qwen 0.5B — 0/7, а прямой Marian после настройки — 1/7. Это не доказывает равную общую способность моделей; набор мал и не заменяет независимую выборку реальных разрешённых переводов с экспертной разметкой.

**Не включать кандидата в рабочий перевод.** Он мал и быстр, но реальные пропуски техники, мебели и денежных условий противоречат цели проекта. Рабочая конфигурация, карточки, автоматическое обучение и сервер не изменялись. Результат закрывает ограниченный исследовательский опыт; задачи качественного двунаправленного перевода и оригинальных китайских объявлений остаются открытыми. Частичная автоматическая проверка не заменяет оценку смысла и естественности носителем языка.
