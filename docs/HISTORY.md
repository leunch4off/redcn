# История, снимки и восстановление

Раздел «История и снимки» хранит до 200 последних действий: генерация, импорт, сохранение, успешное копирование и восстановление. Сохраняются точный заголовок, описание, теги, поля, мебель с количеством, исходные условия, заметки и доказательства разбора.

После «Сохранить объект», «Сохранить правки по этой ссылке» или успешного копирования создаётся PNG текстовой публикации. Снимок относится к версии на момент нажатия. Если разрешения буфера нет, появляется сообщение об отказе: успешное копирование и его снимок не записываются. Верхняя плашка подтверждает результат после записи.

PNG можно посмотреть и скачать у записи истории. «HTML · все поля» выдаёт автономный документ с полным постом, таблицей полей и анализом источника; данные экранированы, скриптов в архиве нет. PNG показывает готовую публикацию и не является фотографией исходной страницы ЦИАН или интерфейса операционной системы. Для чрезмерно длинного текста PNG может быть недоступен; полный HTML остаётся доступен, причина показывается.

«Восстановить в редактор» возвращает точный текст и поля без повторной генерации. Следующая генерация использует текущий словарь и новую подачу. Кнопка ротации заголовков сохраняет ручное описание.

История браузера хранится в IndexedDB, отдельно от черновика. Локальный сайт дополнительно сохраняет события и PNG в `~/.cache/redcn/listings.sqlite3`. История с компьютера доступна при следующем запуске с тем же каталогом данных, включая другой браузер. Это не облачная синхронизация между устройствами.

Экспорт JSON переносит тексты и поля; PNG скачиваются отдельно. Обычная резервная копия редактора включает историю без изображений. PNG/HTML не отправляются в GitHub или Rednote. Переключатели позволяют отключить историю или изображения. При нехватке места сначала пробуется сохранить текст без PNG; сообщение показывает ограничение. Если SQLite недоступен, браузерная копия сохраняется с предупреждением.
