# МОСТ на iPhone

Mac остаётся сервером: открывает Chrome, читает объявление, создаёт китайский текст и сохраняет фотографии. Телефон показывает готовые карточки и отправляет новые ссылки на обработку компьютером. Начальная конфигурация работает внутри одной локальной сети; Mac может быть подключён кабелем к тому же роутеру, к которому iPhone подключён по Wi-Fi.

## Подключение

1. На Mac запустите `start-phone.command` или откройте уже работающий редактор и нажмите «Телефон» в верхней панели.
2. Нажмите «Подключить iPhone» и наведите камеру телефона на QR-код. Если имя компьютера не открывается, выберите числовой адрес в списке над ссылкой и используйте новый QR.
3. Откройте ссылку на телефоне. Одноразовый код действует 10 минут; после подключения сессия сохраняется до 30 дней. Перезапуск сервера сохраняет подключение, явная кнопка «Отключить доступ» отзывает его.

Не открывайте на iPhone `127.0.0.1`: этот адрес относится к самому телефону. Нужен адрес, показанный на Mac. Публичная страница GitHub Pages не соединяется с локальным сервером автоматически.

## Установка на экран «Домой»

В мобильной ленте нажмите «Установить на экран “Домой”». На iPhone откройте сайт в Safari, выберите «Поделиться → На экран “Домой”», затем «Добавить». Если Safari предлагает «Открывать как веб-приложение», оставьте опцию включённой. Запустите МОСТ с новой иконки: кнопка установки будет скрыта.

Обычный Safari не сообщает странице, что вы закончили установку в другом окне; нажатие инструкции само по себе не считается установкой. Если новая иконка попросит подключение повторно, создайте свежий QR-код на Mac. Manifest, значки 180/192/512 и режим standalone поставляются вместе с приложением.

Подтверждение поведения платформы: [Apple — веб-приложение на iPhone](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27), [WebKit — Home Screen для HTTP и HTTPS](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

## Работа с карточками

Открытая лента обновляется примерно раз в пять секунд. Готовые карточки и фото после обработки на Mac появляются автоматически. Можно отправить ссылку ЦИАН/Авито с телефона: Chrome откроется на компьютере. Если площадка запросит проверку, её нужно пройти на Mac. При переключении приложения в фон опрос останавливается и возобновляется при возвращении.

Новые реальные генерации и ручные правки китайского текста в редакторе Mac синхронизируются с телефоном, пока телефонный доступ включён. Учебные примеры в ленту не попадают. Для старых карточек с незагруженными изображениями есть «Загрузить фотографии на Mac».

Когда Mac выключен или недоступен, обновление и загрузка новых изображений прекращаются. Уже открытые данные остаются в текущем окне с отметкой о потере связи; приватные карточки и изображения не сохраняются service worker в офлайн-кеш.

## Фотографии

- «Скачать фото» получает отдельное изображение, «Все фото · ZIP» — фотографии и текст публикации в «Файлы».
- В режиме «Обрезанные» доступны только проверенные кадрированные копии; оригинал не подставляется вместо отсутствующего кадра.
- При доступном системном Share нажмите «Поделиться фото» и выберите сохранение изображения. Данные файла готовятся до нажатия, чтобы сохранить действие пользователя.
- В локальной HTTP-сети системный Share может быть недоступен: откройте фото и удерживайте изображение для сохранения в «Фото».

Сайт не может молча записывать изображения в медиатеку iPhone. Сохранение подтверждает пользователь. [Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share) требует поддерживаемого браузера, защищённого контекста и пользовательского действия.

## Запуск и проверка

```bash
bash start-phone.command
# Или
.venv/bin/python cli/redcn.py --serve --phone --phone-port 8767
```

Редактор работает на loopback-порту 8765; отдельный телефонный сервер — на LAN-порту 8767. Одноразовая ссылка и HttpOnly-сессия требуются для карточек, изображений и команд. Посторонний сайт не получает доступ к API. QR создаётся локально, без передачи кода внешнему сервису. Порт в роутере не открывается автоматически.

```bash
.venv/bin/python -m unittest discover -s tests -p test_phone_relay.py
PYTHONPATH=tests .venv/bin/python -m unittest test_phone_browser -v
```

Браузерная проверка использует Chrome с экраном 393×852 и отдельными тестовыми данными. Физическая установка и системное меню «Фото» требуют проверки на самом iPhone; это не подменяется эмуляцией.
