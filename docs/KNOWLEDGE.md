# Словарь, знания и замечания

Раздел «База знаний» сохраняет примеры, термины, правила и замечания к системе. При включённом запоминании разбор входящего текста и генерация поста добавляют непроверенные записи. Точные повторы объединяются с увеличением счётчика встреч. Максимум — 1000 записей в текущем браузере.

У записи есть тип, название, текст, источник, русская и китайская формулировки, статус и даты. Доступны поиск, фильтр типа, экспорт и импорт. Непроверенная запись не применяется к словарю автоматически: оператор подтверждает пару RU/CN и отдельно нажимает добавление в словарь.

Это долговременная память браузера, а не дообучение языковой модели и не серверная синхронизация. Для другого устройства или другой ссылки сайта используйте JSON-экспорт. Полная резервная копия библиотеки также включает знания и статистику. Очистка хранилища браузера может удалить данные.

## Как сообщать недочёты

Можно написать замечание напрямую в нашем чате. Для сохранения в самом приложении добавьте тип «Замечание / недочёт», опишите фактический и ожидаемый результат, затем экспортируйте базу знаний и отправьте файл в чат для разбора. Экспорт сам по себе не отправляет сообщения и не создаёт GitHub issue.

Новые общие подтверждённые правила можно затем включить в data/knowledge-seed.json новой версии. Частные карточки, данные клиентов и необработанные замечания не коммитятся автоматически в публичный репозиторий.
