# Китайские названия метро в публикациях

`web/metro-names.mjs` форматирует именно поле станции, а не любой русский текст. Порядок: полная точная пользовательская замена, полный китайский вариант из словаря, полный вариант из географического справочника, затем ограниченный частичный перевод.

У «Юго-Западной» уже есть полный вариант **西南**. Наличие отдельного слова «западная → 西» не должно превращать его в смешанное «Юго-西». Полное имя проверяется до частей. Источник проверенного варианта и статус записи остаются в результате функции. Добавлять русский оригинал к уже полному китайскому имени можно параметром `includeRussian:true`; по умолчанию лишнего русского суффикса нет.

Если конкретная полная станция есть в справочнике, но китайское имя отсутствует, применяется небольшой редакционный словарь целых слов транспортной топонимики. Неизвестная часть и полный русский оригинал сохраняются: например, `Ермакова 树林（Ермакова Роща）`. Если буквальное значение покрывает всё имя, оно явно обозначается как значение слова, а не установленное название станции: `Лесной Городок（字面：森林小镇）`. Такие результаты имеют `complete:false`, `needsReview:true`, `source:'partial'`.

Слоги и основы собственных имён не режутся. «Юго», «Луг», «Лук», «Филатов Лук» не исправляются в станции автоматически. Возможные полные совпадения для неоднозначного сокращения возвращаются только как предложения в `candidates`; отображаемая строка остаётся исходной. Латинские номера вроде `Люберцы I` также не превращаются в другие номера или станции. Новых утверждений о работающей линии, маршруте или расположении помощник не добавляет.

API:

```js
translateMetroName(name, {rules, dictionary: DICTIONARY}); // строка для поля метро
resolveMetroName(name, {rules, dictionary: DICTIONARY});   // строка + статус/источник/части
metroNameCoverage({rules, dictionary: DICTIONARY});        // полные/частичные/непереведённые имена
```

Когда `rules` содержит общие и личные правила вместе, нужно передавать и исходный `dictionary`. Это отличает явную новую замену пользователя от общего значения короткого слова. Изменение того же объекта правил учитывается сразу. Подтверждённое пользователем полное правило не переписывается ради удаления пробелов; пробелы между китайскими компонентами убираются только в собственном редакционном частичном варианте.

Географический снимок содержит **453 записи по линиям, 359 различных русских имён и 273 имени с китайским вариантом** до дополнений основного словаря. Это не заявление, что все имена переведены, и не текущая проверка работы станций. Источники, лицензии и уровни проверки сохранены в `GEO_CATALOG.translationSources` и записях справочника; частичный словарь не меняет их на «официальные переводы».
