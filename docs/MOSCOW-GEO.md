# Московский адресный и транспортный справочник

Снимок, полученный 30 октября 2026 года, содержит **453 записи станций по линиям**, **5 537 различных названий улиц/дорог** и **14 480 объектов остановок/платформ**. Одинаковая станция на разных линиях и противоположные остановочные платформы сохраняют отдельные ID. Эти числа не означают 453 уникальные действующие станции или 14 480 уникальных названий остановок.

`data/moscow-geo.json` хранит исходное русское название, тип, источник, координаты при наличии, китайский вариант и статус его проверки. `web/geo-catalog.mjs` — автоматически создаваемая копия для автономного сайта и CLI. Сетевой запрос при обычной генерации не нужен.

## Источники и границы полноты

- [HeadHunter Moscow metro API](https://api.hh.ru/metro/1): все записи ответа, включая МЦК и МЦД-1…4; номера и цвета линий сохраняются как данные источника. В ответе встречаются прежние и перспективные линии. **Действующее движение и актуальность цвета/линии не проверены**: `serviceStatus=not_verified`. Справочник не является маршрутизатором.
- [OpenStreetMap](https://www.openstreetmap.org/relation/102269): все именованные дорожные `way` и остановочные объекты, которые вернул Overpass внутри административной границы Москвы, включая Новую Москву. Время базы, точный запрос и SHA-256 исходного ответа записаны в `sources`. Одинаковые названия дорожных сегментов объединены; остановочные объекты сохраняются отдельно. Наличие имени в OSM не подтверждает юридический статус улицы.
- © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), база под **ODbL 1.0**. Сведения OSM могут содержать пропуски и ошибки. Это полный ответ выполненного запроса, **не заявление о полном официальном реестре Москвы**.
- Официальные наборы Москвы: [вестибюли метро, №624](https://data.mos.ru/opendata/624), [остановки, №752](https://data.mos.ru/opendata/752), [общемосковский классификатор улиц](https://data.mos.ru/classifier/7710168515-obshchemoskovskiy-klassifikator-ulits-moskvy-omk-001-2013-razdel-1). Прямое получение этих выгрузок в проверенной среде вернуло HTTP 403/503. Они **не объявлены импортированными**. Поддержан импорт их доступных JSON/CSV-выгрузок с явной датой и ссылкой.

## Китайские названия

Проверены по [официальному китайскому гиду РАНХиГС](https://www.ranepa.ru/upload/doc/1/Гид%20для%20иностранных%20студентов%20китай%2001271400.pdf): «Юго-Западная» — `西南`, «Тропарёво» — `特罗帕廖沃`, «Проспект Вернадского» — `维尔纳德斯基大道`. Пометка `reviewed` относится к переводу названия, не к состоянию транспортной сети.

Китайское `name:zh-Hans`/`name:zh` из OSM получает `source_supplied`, а не `reviewed`. Дополнительные станционные названия собраны по китайской Википедии: в `data/metro-zh-supplement.json` сохранены конкретные версии исходных страниц, ссылки и лицензия **CC BY-SA 4.0**. Это общеупотребительные варианты из сообщества с пометкой `community`, а не подтверждение официального китайского названия. Непроверенные переводы исходного словаря студии имеют отдельный статус `studio_dictionary`; три проверенных варианта РАНХиГС имеют приоритет над ними. Для неизвестного перевода сохраняется **целое русское название** с китайским обозначением типа, например `地铁站（Неизвестная станция）`. Случайное деление собственного имени на русские и китайские куски запрещено: оно затрудняет поиск станции. Операторский словарь имеет приоритет; существующие утверждённые переводы студии сохраняются.

Это пополнение данных и правил перевода, а не обучение новой языковой модели. Неизвестные переводы остаются видимыми и доступны для последующей проверки.

На этом снимке китайские варианты есть у **273 из 359 различных станционных названий**; 3 названия проверены по официальному гиду, остальные помечены по происхождению. Часть оставшихся имён — станции МЦД и перспективных линий. Отсутствующее китайское имя не мешает поиску и не заменяется придуманным переводом. Улицы и остановки доступны по полному русскому каталогу; сплошной проверенный китайский перевод всех 20 тысяч географических строк не заявляется.

## Обновление

```bash
python3 scripts/update-moscow-geo.py --download-hh --download-osm
```

Для повторяемой локальной сборки из уже загруженных файлов:

```bash
python3 scripts/update-moscow-geo.py --hh-file /path/metro.json --osm-file /path/moscow-overpass.json
```

Официальная выгрузка заменяет только соответствующий тип записей:

```bash
python3 scripts/update-moscow-geo.py --street-export /path/streets.csv --official-source-url https://data.mos.ru/classifier/7710168515-obshchemoskovskiy-klassifikator-ulits-moskvy-omk-001-2013-razdel-1 --official-as-of 2026-10-30
```

Аналогично поддержаны `--metro-export` и `--stop-export`. Пустая/непонятная выгрузка, незавершённый ответ Overpass и повторные ID отклоняются; старый каталог сохраняется. `--render-only` пересоздаёт браузерную копию из JSON без сети и без изменения даты получения данных. Первичный сырой ответ не коммитится: его контрольная сумма хранится в каталоге.

## API

`getGeoStats()` возвращает фактические количества, даты и источники; `searchGeo(query,{kind,limit})` ищет русские/китайские названия; `resolveGeo(name,kind)` ищет точное имя с нормализацией `ё/е`; `geoLabel(record)` показывает китайский вариант с оригиналом; `translateGeo(text,overrides)` заменяет полные названия и словарные фразы одним проходом с приоритетом длинного совпадения. `GEO_CATALOG` содержит все строки и метаданные. При поиске число возвращаемых результатов ограничено 200.

Генератор объявлений использует китайское название без русской вставки для известных переводов; оригинал и двуязычная подпись остаются в справочнике. Это сохраняет китайские теги и не создаёт ложное предупреждение о непереведённом имени. Неизвестное название в посте сохраняется целиком по-русски.
