# Открытый русско-китайский индекс: источник и границы

`data/ru-zh-open-lexicon.json` содержит фактически извлечённые русско-китайские словарные соответствия и засвидетельствованные словоформы. Это отдельный справочный слой, который загружается по запросу. Он не должен встраиваться в начальный HTML или автоматически подменять проверенные правила объявления.

## Состав

Источники — три реальные выгрузки Kaikki.org из китайского и русского Викисловарей:

- [Китайский Викисловарь: русские статьи «俄语»](https://kaikki.org/zhwiktionary/%E4%BF%84%E8%AF%AD/index.html).
- [Китайский Викисловарь: русские статьи «俄語»](https://kaikki.org/zhwiktionary/%E4%BF%84%E8%AA%9E/index.html).
- [Русский Викисловарь: китайский (гуаньхуа)](https://kaikki.org/ruwiktionary/%D0%9A%D0%B8%D1%82%D0%B0%D0%B9%D1%81%D0%BA%D0%B8%D0%B9%20%28%D0%93%D1%83%D0%B0%D0%BD%D1%8C%D1%85%D1%83%D0%B0%29/index.html).

Полные адреса исходных JSONL, их SHA-256 и размеры сохранены в `sources` внутри ресурса. Выгрузки проверены 30 октября 2026; страницы Kaikki отмечают старый postprocessed-формат как deprecated. При изменении формата источник следует проверить повторно, а не молча заменить другим языком.

Извлекаются русские заголовки с китайскими значениями и китайские заголовки с русскими значениями. Не использовался китайско-английский CC-CEDICT и не выполнялся автоматический перевод через английский. Точные дубли удалены. Традиционные иероглифы преобразованы в упрощённые стандартным OpenCC `t2s`; примеры/цитаты и явно помеченные значения `form-of` не копируются как самостоятельные переводы. Словоформы берутся из таблиц исходных статей и ссылаются на русскую лемму, без дублирования китайских значений.

Фактические количества находятся в `stats`: `entries` — уникальные пары значений, `russianKeys` — русские ключи, `attestedFormLinks` — связи засвидетельствованной формы и леммы, `uniqueLookupKeys` — различные нормализованные поисковые ключи. Эти числа нельзя складывать и называть количеством независимых слов. Одно русское слово может иметь несколько китайских значений.

## Использование

Ресурс имеет общий признак `reviewed: false`. Словарное значение может быть определением, редким термином или одним из неоднозначных смыслов. Его можно показать при поиске/проверке собственного текста вместе с исходной статьёй. Он не является гарантией плавного перевода произвольного предложения и не должен автоматически создавать факты о квартире, разрешение животных, сроки регистрации или финансовые условия. Проверенные отраслевые формулировки и ручные правила имеют приоритет.

Строка `entries` имеет схему `[ru, zh, sourceId, sourcePage]`. Исходная статья строится из `sources[sourceId].pageUrlPrefix` и URL-encoded `sourcePage`. Строка `forms` имеет схему `[attestedRussianForm, russianLemma]`. Реальные различия падежа/числа остаются словоформами, а не объявляются новыми леммами.

## Воспроизводимая сборка

```bash
python -m pip install opencc-python-reimplemented
python scripts/build-open-lexicon.py --download --source-dir /tmp/redcn-ruzh-sources
```

Скрипт загружает только фиксированные HTTPS-выгрузки, ограничивает размер каждого источника и записывает их контрольные суммы. Сырые файлы остаются вне репозитория. Без `--download` используются уже полученные файлы из `--source-dir`.
