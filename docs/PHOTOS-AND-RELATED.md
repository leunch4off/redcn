# v7 — фото, кадрирование и похожие объявления

## Как пользоваться

1. Импортируйте объявление или сохранённый HTML. При включённой автозагрузке оригиналы скачиваются в фоне, до трёх одновременно. Они остаются в кеше браузера, а локальный redcn хранит отдельную копию на диске.
2. Нажатие фото открывает диалог внутри сайта. Ссылка «Оригинал у источника» всегда ведёт на проверенный внешний HTTPS-адрес; локальные относительные пути не используются как адрес оригинала.
3. «Скачать фото · ZIP» собирает выбранные оригиналы, `post.txt` и `manifest.json`. Ошибка отдельного файла перечисляется в манифесте. После подготовки также появляется постоянная ссылка «Скачать готовый ZIP».
4. «Обрезать автоматически» в локальной версии запускает OCR метки ЦИАН. На Mac используется Apple Vision; на Linux/Windows — установленный Tesseract. Автоматическая граница выводится из координат надписи, а для слабоконтрастной метки ЦИАН дополнительно проверяется подпись ID справа внизу. Применяются два контрастных варианта нижнего фрагмента. Поле с ID применяется только для источников ЦИАН.
5. Создаётся отдельная JPEG-копия, затем OCR проверяет её. Неуверенное распознавание, метка далеко от края или оставшаяся метка помечаются для проверки. Отсутствие результата OCR не считается доказательством отсутствия всех водяных знаков.
6. В просмотре есть оригинал / копия, четыре отступа в процентах, применение к одному фото или всей выбранной группе, отдельное скачивание и возврат к оригиналу. Ручная граница не называется распознанной автоматически.
7. «Скачать обрезанные · ZIP» включает только созданные копии; необработанные фото не подменяются оригиналами молча. Исключайте фото флажком, меняйте порядок стрелками или выбирайте «На обложку». Выбор, порядок и границы входят в черновик, историю и резервную копию.

## Проверка размеров и форматов

Проверяется содержимое JPEG/PNG/WebP, а не расширение ссылки. До 12 МБ на файл, до 40 МП, минимальная сторона 32 px. EXIF-ориентация применяется до расчёта размеров. Изображение не растягивается; каждая граница вычисляется по собственным ширине и высоте. Сохраняется не менее 55% площади. В автоматическом режиме дополнительный предел удаления одного края — 28%.

Оригиналы проверяются по SHA-256, хранятся отдельно от производных и повторно используются по URL. Смена границы всегда начинает обработку с оригинала. Файлы пользователя, кеш и фотографии не публикуются в GitHub.

## Среды

- Локальный сайт: скачивание через проверяемый Python HTTPS-клиент, SQLite/диск, OCR и ручное кадрирование. `start-redcn.command` устанавливает `cli/requirements-media.txt`. В Python.org macOS используется certifi с включённой проверкой TLS. При сетевом timeout допускается одна повторная попытка; HTTP-отказы и проверки источника не обходятся.
- Sites: проверенный серверный маршрут `/api/photo` для изображений, кеш браузера и ручные границы. OCR выполняется в локальной версии.
- GitHub Pages: прямое чтение CDN зависит от CORS источника. При отказе можно прикрепить скачанный оригинал либо открыть локальный redcn. Недоступный файл явно отмечен; успешная загрузка не имитируется.

Фото можно прикрепить в нужную ячейку вручную. Это помогает при недоступности источника; локальная версия сохраняет прикреплённый файл для OCR. Фото не входят в обычный JSON-экспорт; изображения скачиваются ZIP отдельно, JSON переносит порядок и параметры кадра.

## CLI

```bash
.venv/bin/python cli/redcn.py --html saved.html --download-photos output/photos --crop-photos --json --output output/listing.json
```

Явная граница вместо OCR:

```bash
.venv/bin/python cli/redcn.py --html saved.html --download-photos output/photos --crop-bottom 23
```

Оригиналы и копии получают разные имена. Итог кадрирования и причины проверки находятся в `manifest.json`.

## Похожие объявления

Сохранённая страница и снимок видимого Chrome передают ссылки рекомендаций отдельно от данных основной квартиры. Разбор не запускает JavaScript страницы. Повторные ссылки удаляются; текущая карточка, ссылки авторизации и неподдерживаемые домены исключаются.

Список объединяется с сохранёнными объектами у того же метро или в радиусе 3 км по координатам. Совпадение станции должно быть явным; расстояние показывается по прямой, без выдуманного времени пешком. Кандидаты без подтверждённого метро остаются с соответствующей подписью. Фильтр оставляет только совпадающие станции.

«Взять в редактор» сначала сохраняет текущую редакцию в историю. Объект библиотеки открывается со своим текстом. В локальной версии внешняя ссылка запускает отдельный импорт; на Pages выбирается URL для последующего импорта HTML/JSON. Доступность объявления и актуальность цены проверяются при его загрузке.

Если HTML не содержит карточек рекомендаций, приложение сообщает об этом. Можно добавить прямые ссылки вручную. Автоматический поиск всей выдачи ЦИАН/Авито и обход защиты в эту функцию не входят.

## Подтверждённые реальные фото

На Mac скачаны все шесть оригиналов приложенного объявления: 1280×978 и 720×960, фактический формат WebP при `.jpg` в URL. На четырёх Apple Vision автоматически определил границу, сохранил копию и повторно проверил результат; два слабоконтрастных фото требуют ручной границы. Пример 1280×978 → 1280×759 просмотрен визуально, метка и ID остались за кадром.

Источники реализации: [Apple Vision](https://developer.apple.com/documentation/vision/recognizing-text-in-images), [Pillow: crop и ограничения размера](https://pillow.readthedocs.io/en/stable/reference/Image.html), [EXIF orientation](https://pillow.readthedocs.io/en/stable/_modules/PIL/ImageOps.html).
