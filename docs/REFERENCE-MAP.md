# Вложение пользователя → функции redcn

Оригинал: `Вставленный текст(20261029-200818).txt`. Точная копия: [user-listing-examples.txt](references/user-listing-examples.txt). Файл сохранён без нормализации и содержит пользовательскую подборку прежних публикаций, включая повторы.

| Наблюдение в примерах | Функциональное назначение | Задачи |
| --- | --- | --- |
| Название перед описанием, эмодзи, W/万, метро | Отдельные динамические заголовки, варианты и копирование | RCN-081…090 |
| Короткая и подробная версии одной квартиры | Форматы compact/detailed/story | RCN-091…100 |
| Studio, отдельная спальня, кухня-гостиная | Явная планировка и площади зон | RCN-074, RCN-094 |
| Мебель и техника по комнатам | Отметки существующих удобств и раздельные блоки | RCN-074, RCN-092 |
| «Стиральная машина будет установлена» | Не считать будущую установку существующей техникой | RCN-074, RCN-079 |
| Несколько станций с разными временами | Независимые маршруты и способы поездки | RCN-131…140 |
| МГУ, РУДН, МГИМО, РАНХиГС | Алиасы вузов, целевые кампусы, контекстные теги | RCN-114, RCN-123, RCN-141…150 |
| Цена на 2/3/4 человек | Проверяемый расчёт общей аренды на человека | RCN-086 |
| Залог, счётчики, все включено, каникулы | Отдельные условия и платежи | RCN-151, RCN-152, RCN-159 |
| Дети, питомцы и короткая аренда | Подтверждённые условия без безусловных обещаний | RCN-157, RCN-158 |
| Регистрация, трансфер, багаж, перевод документов | Редактируемые услуги и поддержка после заселения | RCN-153…156 |
| Варианты слов и смешение RU/CN | Интерактивный двуязычный редактор и словарь замен | RCN-101…110 |
| Теги станций, вузов, квартир и студии | Контекстный каталог с объяснением выбора | RCN-121…130 |

Это редакционные референсы, а не подтверждение доступности объектов, текущих цен и маршрутов. Чужие факты не подставляются автоматически в новые объявления.
