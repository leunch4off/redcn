## Аналитика в redcn

Реализован импорт CSV/JSON из доступного оператору источника. Разделяются tag, keyword/topic/note, entity, source, timezone, sourceSystem и daily/cumulative.

- Суммируются только ежедневные значения одной серии; неполный период имеет явную отметку покрытия X/Y.
- Для накопительного счётчика нужны точные снимки до начала периода и на его конец. Один текущий счётчик не даёт дневной, недельный или месячный результат.
- Индекс поиска усредняется и никогда не выдаётся за число поисков.
- CTR считается только для полных согласованных рядов clicks/impressions.
- Просмотры, лайки, сохранения и клики не подменяют друг друга.
- Данные остаются в браузере и входят в резервную копию; страница GitHub Pages не публикует пользовательские выгрузки.
