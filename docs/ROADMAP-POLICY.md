# Правила Roadmap

- Главный машиночитаемый реестр — plan.json. Читаемая копия — ROADMAP.md. GitHub issue с названием Roadmap отражает тот же набор.
- Исходные 200 устойчивых ID RCN-001…RCN-200 сохраняются. С 30.10.2026 по запросу пользователя новые потребности добавляются последующими ID; задачи не удаляются, их ID не меняются и повторно не используются. plan.total равен фактическому числу задач.
- У каждой задачи есть назначение, критерий приёмки, приоритет, зависимости, статус и ссылки на доказательства.
- status=done и [x] разрешены только после выполнения всего критерия. Создание макета, пункта меню или заглушки не означает готовности функции.
- Если выполнена только часть, задача остаётся planned; конкретный результат описывается в журнале выпуска.
- Проверки и ограничения фиксируются в docs/VERIFICATION.md; плановая функция не называется реализованной.
- Перегенерация Markdown: node scripts/render-roadmap.mjs. Итог должен содержать plan.total checkbox.
- Изменения Roadmap и кода сохраняются в git. Главный issue остаётся открытым до полной приёмки всех задач.
