# Быстрое чтение блоков объявления

Chrome-импорт по умолчанию использует `sections`. Чтение начинается после получения документа (`commit`), без ожидания `DOMContentLoaded`, сторонних отложенных скриптов или завершения всех сетевых запросов:

1. После появления распознанных блоков сразу прокручивает к слайдеру фотографий.
2. Проверяет загруженные изображения в видимой части галереи. Готовый блок пропускается без фиксированной паузы.
3. Переходит к описанию, затем к характеристикам и оснащению. Отдельные незаполненные блоки мебели/техники также посещаются, даже когда основная информация уже появилась.
4. Если нужные блоки не распознаны либо остались неполными, выполняет ограниченную прокрутку страницы как запасной вариант.

Точные селекторы взяты из существующего парсера ЦИАН/Авито: `OfferGallery`, `Gallery`, `OfferDescription`, `Description`, `GeneralInfoSection`, `FeaturesItem`, `OfferSummaryInfoGroup`, `OfferFactItem`, `ObjectFactoidsItem`, а также `item-view/item-description` и `item-view/item-params`. Рекомендации других квартир исключаются.

```sh
.venv/bin/python cli/redcn.py --browser --browser-scroll sections 'https://www.cian.ru/rent/flat/…/'
```

Для прежнего прохода по всей странице укажите `--browser-scroll page`. Аргумент действует для одиночного и пакетного CLI-импорта. Сайт использует новый режим по умолчанию.

Если блок ещё не готов, проверка повторяется с интервалом до 80 мс; максимум ожидания одного типа блока — 1,5 секунды, всего этапа — 6 секунд. Запасная прокрутка использует оставшуюся часть общего 12-секундного бюджета чтения. Срок импорта `--browser-timeout` имеет приоритет. Кадр отрисовки запрашивается только для неполного блока и имеет таймер-страховку для фонового окна. Браузерная проверка источника остаётся ручной и приостанавливает короткий бюджет чтения.

В событиях прогресса указаны конкретные блоки, количество найденных кандидатов фотографий и факт готовности. `capture.strategy`, `capture.sections`, число чтений и затраченное время доступны в результате. `completed` для `sections` означает готовность распознанных разделов, а не достижение конца страницы. Готовность видимых изображений не доказывает, что найдены все фотографии. Обработка оригиналов и проверка подрезки выполняются затем отдельно.

Импорт использует собственное окно/профиль и новую вкладку. Он не подключается к пользовательскому Chrome, не нажимает слайды, соглашения или защиту сайта. Изображения виртуализованной галереи сохраняются по накопленным URL, а исходный адрес проверяется перед каждым чтением. При отмене/ошибке собственное окно закрывается, чужие окна не затрагиваются.

Проверки: `tests/test_section_scroll.py` — готовые разделы без задержек, ожидание незагруженного изображения, ограничение неизвестного макета, отмена/неподдерживаемый адрес, ручная проверка без расхода короткого бюджета, загрузка отложенных описания и мебели, высокий слайдер, фоновое окно без кадров анимации и чтение до задержанного `DOMContentLoaded`. Четыре сценария требуют установленного Chrome/Playwright; остальные выполняются без браузера. Прежние `test_browser_capture.py` и `test_local.py` сохраняют приёмку запасного прохода и владения вкладкой.

## Проверка на Mac · 30 октября 2026

Девять сценариев прошли без ошибок и пропусков за 14,215 с, включая четыре настоящих сценария Chrome. Загруженные разделы с высоким слайдером прочитаны за 0,381 с, по одному чтению на раздел. Отложенные описание и отдельный блок техники — за 0,865 с; блок техники посещён дополнительно после основной информации. При отключённых кадрах анимации — 0,985 с. Документ с намеренно задержанным сторонним скриптом прочитан за 0,360 с до `DOMContentLoaded`. Это измерения локальных тестовых страниц, не обещание скорости любого источника.

Отдельный публичный пример ЦИАН `321415127` не удалось открыть: источник вернул Chrome `net::ERR_TIMED_OUT` на этапе навигации, завершение за 37,576 с. До блоков объявления импорт не дошёл, поэтому этот запуск не подтверждает скорость чтения реального ЦИАН. Использовались собственные временные профиль и контекст; Chrome закрыт, рабочие карточки и кеш не изменялись.
