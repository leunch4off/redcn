# Адаптеры источников

Сайт и CLI используют один формат карточки и один генератор. Разбор DOM и селекторы каждой площадки изолированы:

| Назначение | ЦИАН | Авито |
| --- | --- | --- |
| HTML и поля | `web/source-adapters/cian.mjs` | `web/source-adapters/avito.mjs` |
| Контракт Chrome | `cli/source_adapters/cian.py` | `cli/source_adapters/avito.py` |
| Фикстура | `tests/fixtures/cian-54.html` | `tests/fixtures/avito-52.html` |

`web/source-import.mjs` — только выбор адаптера по известному URL или первому основному маркеру документа. Переданный домен имеет приоритет. `web/source-adapters/html.mjs` читает инертный HTML, не исполняет скрипты. `cli/browser_dom.py` содержит общую механику снимка и проверки готовности, `cli/browser_import.py` — запуск, проверку адресов, сроки и прокрутку. Контракты обеих площадок не объединяются в один набор селекторов.

## Авито

- Цена: `item-view/item-price`, `item-view/item-price-container`, запасные `#item-price` и `itemprop=price`.
- Название: `item-view/title-info`.
- Фото: только `item-view/main-gallery`, включая доступные lazy/srcset URL. OG-коллаж и рекомендации не используются.
- Описание: `item-view/item-description`.
- Повторный `item-view/item-params`: каждый блок разбирается отдельно по заголовку «О квартире», «Условия аренды», «Правила», «О доме».
- «Особенности» и «Расположение»: заголовки смыслового блока. Координаты — `item-map-wrapper` / `data-map-lat` / `data-map-lon`; способ пути — только подпись или именованная иконка, не сам номер минут и не цвет кружка.

Структурированные записи нормализуются в общие имена карточки: цена, комнаты, площади, этажи, оснащение, правила, адрес, координаты и маршруты. Исходные строки сохраняются в `sourceAudit`. Запрет и неизвестное значение не становятся разрешением; комиссия в рублях не становится процентом. «Спальные места» и «хранение одежды» сохраняются как общие формулировки и не доказывают наличие конкретной кровати или шкафа.

Версия `parserVersion=avito-v1` заставляет следующий запрос перечитать прежний неполный кеш Авито. Сохранённые карточки не переписываются пакетно. Кеш ЦИАН работает по прежним правилам.

## Проверки

`node --test tests/avito-source.test.mjs tests/source.test.mjs`

`PYTHONPATH=tests:cli python -m unittest test_source_adapters test_browser_capture test_section_scroll`

На Mac с установленным Playwright/Chrome дополнительно:

`PYTHONPATH=tests:cli .venv/bin/python -m unittest test_avito_browser test_section_scroll`

Фикстуры обезличены, изображения синтетические. Наличие рабочих фикстур не подтверждает живой доступ к площадке: проверка источника остаётся ручной при её запросе. Тесты не создают живые импорты и не расходуют кампанию ЦИАН. История реальной попытки и ограничения — в `VERIFICATION.md`.
