# Источники объявлений и расчёт маршрута · v26

Проверено 1 ноября 2026 года. Код не превращает закрытый API кабинета в общедоступный поиск и не заменяет автобус автомобильным профилем.

## Реальный маршрутный провайдер

Добавлен `cli/route_provider.py`: обычный явно запрашиваемый расчёт Valhalla/FOSSGIS по двум выбранным координатам. Работают только пеший и автомобильный режимы. Поля квартиры, описание, имена, фотографии, cookies и ключи сервису не отправляются. Числа — оценка по дорожной сети, а не физически измеренная поездка, пробки или расписание транспорта.

- Авторизованные GET `route-provider`, POST `route-provider/calculate`. Вызова при открытии страницы, фонового мониторинга или автоматического включения нет.
- Жёсткий срок собственного сетевого процесса — 12 с; отдельный процесс ограничивает также DNS и чтение тела. Фиксированный HTTPS-host, проверенные публичные DNS-адреса, проверка сертификата/SNI и запрет перенаправлений. Ответ ограничен 2 МБ.
- Один расчёт одновременно, не чаще раза в 5 с; одинаковые запросы используют приватный кеш на 600 с. Дата исходного расчёта сохраняется. Кеш разделён папкой рабочего пространства и ограничен 100 записями.
- В форму Mac и телефона добавлены выбранные точки, вход дома/выход метро, доступность, дата и источник проверки. Закрытый, неизвестный, устаревший вход или центр здания не проходят режим «только входы». Вход не подменяется центром здания. Отдельно проверяется отклонение конца дорожной геометрии: более 30 м требует исправить точку.
- После изменения точки/режима прежние вычисленные время и расстояние сбрасываются. Поздний ответ не заменяет изменённый черновик. После истечения срока расчёт виден как устаревший.
- Форма, map-ссылки и сохранённые поля используют те же выбранные точки. Отдельный исторический адрес вуза не возвращается в расчёт через вручную введённые координаты. Опубликованная точка кампуса берётся через проверку `verifiedCampusPoint`, а не из одного совпавшего имени.
- Производная атрибуция OSM/Valhalla присутствует в интерфейсе и PDF-модели даже при отсутствии координат самой квартиры.

Официальные источники:

1. [Valhalla: публичный сервер](https://valhalla.github.io/valhalla/start/introduction/) — полный граф мира, fair use, запрос идентифицирующего `X-Client-Id`. В коде используется `github.com/leunch4off/redcn`. Авторы просят сообщать им о приложениях для конечных пользователей; сообщения за пользователя не отправлялись.
2. [OSM Deutschland: сервисы](https://www.openstreetmap.de/nutzen/dienste-osm-de/) — публичное описание API-интеграции маршрутизаторов.
3. [API маршрута](https://valhalla.github.io/valhalla/api/route/api-reference/) — координаты, отдельные pedestrian/auto и multimodal-профили. `bus` означает профиль движения автобуса, а не готовое расписание общественного транспорта; этот режим нашим адаптером отвергается.
4. [Лицензия Valhalla](https://github.com/valhalla/valhalla/blob/master/COPYING) — MIT; [данные OpenStreetMap](https://www.openstreetmap.org/copyright) — отдельная атрибуция/ODbL. Бесплатный публичный demo не имеет договорного SLA; это не обещание бесплатного промышленного сервиса.

Реальный ответ по двум опубликованным точкам МГУ: **1,085 км / 769,302 с**, сетевой конец удалён от заданных координат на **14,86 / 25,86 м**. Это точки зданий, а не доказанные доступные двери. Полный метод, дата, SHA ответа и версия исполненного кода: [receipt](benchmarks/route-provider-valhalla-20261101.json). Executor использовал свой обычный системный сетевой транспорт; штатный bounded/pinned путь проверяется отдельно на Mac. Воспроизведение одним запросом: `scripts/pilot-route-provider.py --output <receipt.json>`; тестовые папки временные, рабочая библиотека не открывается.

## Общественный транспорт: измеренная граница RCN-301

[Официальный transit availability API](https://github.com/valhalla/valhalla-docs/blob/master/transit-available/api-reference.md) вернул HTTP 200 и `istransit=false` для двух запрошенных радиусов по 2 км: опубликованная точка физфака МГУ и район Красной площади. [Ответ и дата](benchmarks/route-provider-transit-capability-20261101.json). Это проверка выбранных точек, не доказательство отсутствия GTFS во всей Москве. Автобусы и пересадки адаптер не выдумывает.

[Яндекс JS API](https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/dg/concepts/router/multiRouter) документирует `masstransit` и транспортные сегменты. [Условия](https://yandex.ru/legal/maps_api/ru/) требуют ключ и имеют ограничения для закрытых проектов, хранения ответов и использования данных. [Тарифная страница JS API](https://yandex.ru/dev/tariffs/doc/ru/jsapi/prices/) разделяет открытый и закрытый доступ; цены панорам нельзя объявлять ценой маршрута. Условия выгрузки маршрутов в наши HTML/PDF и подходящий договор для закрытого инструмента не подтверждены. Ключ владельца не предоставлен; доступ или покупка за него не оформлялись. Поэтому RCN-301 не отмечается выполненным только по наличию ссылки на Яндекс.

## Разрешённые реальные структурные fixtures

Из новых пользовательских вложений получены две обезличенные структурные производные: ЦИАН и Авито. Сохраняются теги и ограниченный набор selector-атрибутов; все значения полей и адреса фото заменены вымышленными. Raw HTML, JavaScript, исходные описания, контакты, HTTP-заголовки, ресурсы webarchive и оригинальные URL фото в репозиторий не попадают. Скрипт никогда не исполняет предоставленную страницу.

- `cli/source_schema_fixture.py`, `scripts/sanitize-source-schema.py`.
- `tests/fixtures/{cian,avito}-user-observed-v26.html` с отдельными manifests и SHA.
- [Общий manifest](../tests/fixtures/source-schema-corpus-v26.manifest.json) явно учитывает, что два предоставленных Cian webarchive побайтно совпадают: это **один**, а не два независимых варианта ЦИАН.
- Для обычного Chrome подготовлен `--browser-script`: возвращает только ту же обезличенную структуру и хеш исходного DOM; исходный HTML, ресурсы и контакты из браузера не возвращаются.

Обе производные проходят реальные статические адаптеры с вымышленными проверочными значениями 80 000 / 54 м² / 2 комнаты / 5 из 17. Эти числа не являются характеристиками исходных квартир. RCN-020 требует несколько реальных вариантов именно ЦИАН; один Cian и один Avito это условие не заменяют.

## Доступ к поиску ЦИАН и Авито

[Циан API для кабинета](https://www.cian.ru/novosti-teper-dostup-k-tsian-api-mozhno-poluchit-prjamo-v-lichnom-kabinete-329732/) описывает работу профессионального рекламодателя с собственным кабинетом. [Avito API каталог](https://developers.avito.ru/api-catalog) и Item API относятся к объявлениям авторизованного пользователя. Это не подтверждение разрешённого API глобального рынка. Прямое чтение указанных страниц из текущего исследовательского транспорта вернуло 403/недоступность; эту ошибку не скрывают ссылкой на сторонний scraper.

В проекте уже есть раздельные Cian/Avito адаптеры наблюдаемой HTML-выдачи и обычного Chrome, дедупликация кандидатов и явное состояние ручной проверки. Успех JSON unit-теста не доказывает живой доступ. RCN-037/038 остаются зависимыми от реально доступной разрешённой выдачи/API; RCN-325 требует успешный обычный живой импорт, который проверяется отдельно на Mac. Ни private API, ни прокси-ротация, ни обход защиты для закрытия счётчика не добавлены.

Публичные архивы проверяются только как источник исторических схем, не как способ получить действующее объявление в обход текущей проверки. [Common Crawl Terms](https://commoncrawl.org/terms-of-use) разрешают доступ к сервису, сохраняя отдельные права/условия исходных сайтов; наличие страницы в архиве не объявляется открытой лицензией её полного содержимого.

Запрос метаданных Common Crawl по актуальному официальному индексу CC-MAIN-2026-43 завершился HTTP 504; уточнённый запрос одной точной ссылки — сетевым timeout. Сырые архивные страницы не получены, новый реальный вариант ЦИАН из этих запросов не заявляется.
