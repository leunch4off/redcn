# Проверка выпуска v3

## Результат

Roadmap содержит 200 устойчивых ID. На этом этапе отражены **119 выполненных пунктов** (включая функции предыдущей версии), **81 остаются в плане**. - `python3 cli/redcn.py --input examples/listing.txt --data examples/fields.json --variant 1 --json --output <temporary-file>` — реальный запуск общего генератора без сети; цена, 3 заголовка, теги МГУ/кампуса и unknown проверены.
- `node scripts/build.mjs` и `node scripts/validate-artifact.mjs` — сборка и валидный default.fetch.
- В браузере превью: создание примера, CN→RU «冰箱 — Холодильник», замена на 冷藏箱, отмена с точным восстановлением, замена всех совпадений заголовка, ротация заголовка с сохранением описания, сохранение объекта, 200 карточек Roadmap и ссылка issue, импорт JSON-результата Python (цена 85 000, заголовок и теги восстановлены).

## Границы проверки

Живой импорт конкретного объявления ЦИАН/Авито и загрузка реальных фотографий в этой сессии не проверялись: пользователь не дал конкретную актуальную ссылку. HTML, фото, ошибки и сетевые политики проверены на локальных fixtures и mocks. Доступ источников с защитой не гарантируется.

Браузерная приёмка выполнена на desktop-превью, а не на мобильном устройстве. Автоматическая CI-регрессия интерфейса пока не реализована. Офлайн-словарь не переводит любые произвольные китайские слова: неизвестные записи нужно добавлять.

Новые ссылки для batch передаются оператором. Автоматический поиск по выдаче, реальные маршрутные API, серверная синхронизация, постоянный мониторинг, уведомления и полный медиаэкспорт остаются открытыми задачами. Приватность сайта и репозитория сохранена.

Публикация v3 подтверждена Sites: deployment appgdep_6ae3ac3068d881918ac7a2148ebe3847, status=succeeded. После этого RCN-194 отмечен выполненным; текущая правка плана содержит 119 выполненных пунктов и 81 открытый.

## v4 — исследование, база знаний, аналитика и автономная сборка

- Web-поиск по китайским источникам и прямой поиск Rednote выполнены. Подсказки получены, результаты потребовали входа. Реальные показатели московских тегов за периоды не получены; отчёт содержит «Нет данных».
- `node --test tests/*.test.mjs` — 33 проверки. Новые сценарии: отсутствующие значения, частичные периоды, накопительные снимки, различие индекса и поисков, запрет смешения источников/часовых поясов, CTR, CSV, дедупликация, память непроверенного контента.
- 10 Python-проверок остались зелёными.
- `node scripts/validate-pages.mjs` проверяет JavaScript внутри реально собранного HTML, отсутствие корневых зависимостей и наличие JSON-справочников.
- Исправлена ошибка сборки replacement-string: `$&` из кода словаря мог повторно вставлять исходный script-тег. Сборка использует callback замены; автономный inline-модуль прошёл синтаксическую проверку и браузерную приёмку по /pages/.
- В браузере проверены готовый Pages-HTML, генератор, аналитика с отсутствующими значениями, источники исследования и сохранение замечания после перезагрузки. История клиентского хранилища не включается в сборку.
- Проверка исходников на характерные форматы ключей перед публичной публикацией не выявила совпадений.

GitHub Pages v4: https://leunch4off.github.io/redcn/ — status=built, public=true, source main/docs. Проверен действующий HTML и отсутствие ChatGPT-входа. Репозиторий открыт по прямому указанию пользователя; рабочее клиентское хранилище не загружалось в git.


## v5 — локальный Chrome

- 34 Node + 22 Python проверки: Markdown/приклеенная ошибка, один переход HTTP→Chrome, повторное чтение кеша, отсутствие ложной CAPTCHA по имени JS-файла, видимый запуск/стабильность/закрытие/отмена на mock, локальный job API, сохранение результата и заметок, проверка Host/Origin/токена, неизменность цены/площади/залога/маршрута при вариации.
- Worker и автономный Pages HTML проходят сборку и синтаксическую проверку.
- В desktop-превью проверены заметка CN | RU | замена и русский смысл фразы. Браузерные проверки не являются заявлением о доступности конкретного живого объявления.
- Локальные ссылки работают только при запущенном сервере на том же компьютере, порте и каталоге кеша. Записи хранятся в SQLite, личные данные не входят в git.
- Для Chrome нужен необязательный Playwright и установленный Google Chrome. Проверка источника остаётся ручной; отсутствие блокировок и постоянная доступность CIAN/Авито не гарантируются.

Проверка на Mac владельца: Python 3.11, Node 24, Google Chrome 156; Playwright 1.64.1 установлен в .venv отдельной копии redcn-v5. Генератор выдал три заголовка; локальный сервер сохранил результат в SQLite и вернул его через API по ссылке /listing/<id>. Первый запуск установленного Chrome занял около 55 секунд, поэтому лимит старта увеличен с 30 до 90 секунд; отдельный тест видимого запуска/закрытия завершился успешно. Добавлен явный выбор совместимого Chromium / Chrome for Testing без изменения настроек защиты браузера.

Живой запуск указанной владельцем ссылки https://www.cian.ru/rent/flat/300691182/ через Google Chrome не завершился чтением карточки: навигация превысила 45 секунд и осталась на about:blank. Это сетевое ожидание ошибочно выдавалось за неверную схему ссылки; исправлено отдельным regression-тестом. Чтение объявления и фото по этой ссылке не объявляется подтверждённым.
