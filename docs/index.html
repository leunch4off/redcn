2 Данные и расположение

Несколько станций и вузов

Одна строка — один маршрут. walk = пешком, bus = автобус, metro = метро, public = общественный транспорт. Эти строки заменяют одиночное поле метро выше.

Без времени маршрут выйдет с пометкой «уточнить». Вузы добавляются в теги только при наличии в карточке.

Факты, которые делают текст живым

Импорт статистики

CSV/JSON из доступного вам кабинета или собственного журнала. Каждая строка содержит дату, метрику, значение, объект, источник и тип daily/cumulative. Файл не отправляется на сервер.
